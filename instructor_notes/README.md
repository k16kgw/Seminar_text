# 教員用：卒業研究の完了基準と運用

:::{warning} 非公開資料
このディレクトリは教員用である。学生向けMySTの目次には追加しない。`myst.yml` には、必要な場合だけ有効化できるコメント済みの目次例を置いている。
:::

## このノートの目的

学生向け教材では、卒業研究の最終比較や完成コードを与えない。一方で指導側には、どこまで到達すれば卒論として成立するか、困難が生じた場合にどこへ縮退できるかという見通しが必要である。

本ノートでは各テーマについて、次の3段階を定める。

| 水準 | 意味 |
| --- | --- |
| 最低成立線 | この条件を満たせば、限定された問いに対する再現可能な数値研究としてまとめられる |
| 標準ゴール | 当初の卒研テーマとして期待する到達点 |
| 発展ゴール | 時間と理解に余裕がある場合だけ進む内容 |

最低成立線は「結果が予想どおりであること」ではなく、**問い・実装・検証・比較・限界が一貫していること**で判定する。

## 全テーマ共通の完了条件

### 1. 問い

- 「何を変えると、何がどう変わるか」を1文で書ける。
- 比較対象と固定条件を列挙できる。
- 教材の再実行だけでなく、学生自身が決めた要素が最低1つある。

### 2. 再現性

- 実行環境と主要パッケージを記録している。
- 生データ、前処理、計算結果を区別して保存している。
- 乱数seedとパラメータを記録している。
- 最初から実行して主要図を再生成できる。

### 3. 数値的な検証

テーマに応じ、少なくとも1つを行う。

- 解析解との比較
- 格子幅・時間刻み依存性
- 保存量または収支
- 単体テスト可能な小問題
- 複数seedと反復回数依存性
- 既知の極限・特殊ケース

### 4. 比較

- 1回に変える主要因を1つへ限定した比較がある。
- 比較条件が公平である理由を説明できる。
- 図だけでなく数値表がある。
- 平均だけでなく、誤差・分布・感度のいずれかを示す。

### 5. 考察

- 予想と一致した点・しなかった点を分けている。
- モデルから言えることと言えないことを区別している。
- 結果が変わりうる仮定を最低2つ挙げている。
- 次に必要なデータまたはモデル拡張を述べている。

## 段階ゲート

| ゲート | 教員が確認するもの | 未達の場合 |
| --- | --- | --- |
| G0 | 問い、対象、比較条件を1ページに整理 | 実装を増やさず問いを狭める |
| G1 | 教材Notebookの再現と説明 | 基礎章へ戻る |
| G2 | 基準モデルの検証結果 | 研究用拡張を止めて検証する |
| G3 | 学生独自の変更を1つ実装 | 変更をさらに小さくする |
| G4 | 基準条件との比較図・表 | 評価指標と反復方法を見直す |
| G5 | 感度・限界・再現手順 | 新機能を止めて執筆へ移る |

## 完了可能性を高める運用

### 早期に凍結するもの

- 基準版コード
- 主評価指標
- 最低限の比較条件
- 図の役割
- データ取得期限

### ストップルール

- 2週間以上、同じ技術的問題で主結果が出ない場合は縮退案へ移る。
- 新しい機能は、既存の主要図が再生成できる状態でのみ追加する。
- データ取得が期限までに完了しなければ、公開・仮想データを用いる方法論研究へ変更する。
- 高度な最適化・FEM・機械学習は、最低成立線を満たした後だけ許可する。

## 卒論の最小構成

1. 問題設定と先行研究
2. 最小モデルと仮定
3. 数値計算法と検証
4. 比較実験の条件
5. 結果
6. 感度・不確かさ
7. 限界と今後の課題

結果が「明瞭な差なし」「複数パラメータが同程度」「単純モデルでは説明困難」であっても、検証と考察が成立していれば卒論になりうる。
