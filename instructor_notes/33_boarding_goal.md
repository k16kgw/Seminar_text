# 教員用：電車乗降と行動ルールのゴール

:::{warning} 非公開資料
行動別の優劣や推奨行動を学生用教材へ結論として掲載しない．教育用モデルから実際の鉄道運用を断定しない．
:::

## 卒研としての中心

ドア付近の局所的な行動ルールを操作的に定義し，同一条件・複数seedのエージェントシミュレーションによって，完了時間や混雑指標の分布がどう変わるか評価する．

## 最低成立線

1. 31章の一斉更新CAを再現し，一方向流の完了と対向流の停止を区別する．
2. 人数保存，排他制御，終了条件を小配置で検証する．
3. 基準条件を複数の初期配置で実行し，完了率と上限制限時間の分布を得る．未完了を完了時間として集計しない．
4. 観測可能な代替行動ルールを学生が1つ定義する．
5. 代替ルールを人数1～3人の配置で単体確認する．
6. 保存した同じ初期配置を基準と代替に複製し，初期配置用・更新用・行動割当用の乱数を管理する．
7. 対応差，完了率の変化，推定の不確かさを示す．
8. 人数またはドア幅のどちらか1つで感度分析を行う．

実動画がなくても，理想化された行動ルールの数値実験として成立させられる．

## 標準ゴール

- 観察・先行研究または明示した仮定に基づく行動を1つ定義し，十分に検証する．種類の追加は発展とする．
- 行動者割合を調べ，固定人数方式と独立割当方式，有限人数での実現割合を区別する．
- 予備計算で対応差のばらつきを測り，精度目標から本計算の反復数を決める．
- 完了時間，ドア前密度，停止回数など複数指標を比較する．
- 更新順序，人数，ドア幅への感度を調べる．
- 可能なら少量の実測値とオーダーまたは傾向を比較する．

反復数は固定値を盲目的に採用せず，標準誤差と計算時間から決める．

## 発展ゴール

- 動画からの軌跡抽出
- 行動分類の観察者間一致
- 連続空間・社会力モデルとの比較
- 複数ドアと経路選択
- 異質な歩行速度・目的を持つ集団
- ルール混合比の最適化

## 教員が期待してよい定性的傾向

- 1回のseedでは条件の順位が逆転しうる．
- 平均が改善しても，遅い外れケースが増える可能性がある．
- 行動者割合に対し単調でない応答が生じうる．
- 更新順序や衝突解決が結果へ強く影響しうる．
- 高密度条件でのみ行動差が現れる可能性がある．

特定行動が常に優位になることを完了条件にしない．

## 受け入れ目安

- 初期配置の内容が基準・代替で一致することを確認している．同じseedだけで対応を保証したと考えていない．
- 人数が生成・消失しないことをテストしている．
- 反復の独立単位を定め，平均差の標準誤差と未使用配置での検証を示している．
- ルール以外の条件が一致していることを表で示す．
- 完了，右打切り，証明された吸収状態を区別し，上限ちょうどの完了も検査している．
- 代替ルールでも旧デッドロック判定が有効か再検証している．
- 領域端への到達時間を，実際の停車時間と同一視していない．
- 結果の分布または信頼区間を示している．

## 必要な図

1. 空間と更新規則の模式図
2. 基準条件の完了率・上限制限時間分布と，未完了の内訳
3. 基準と代替ルールの比較分布
4. 行動者割合または主要条件への応答
5. 密度分布または感度分析

## 縮退案

| 問題 | 縮退後の卒研 |
| --- | --- |
| 実動画を取得できない | 理想化ルールの数値実験と感度分析に限定 |
| 複雑な移動ルールが不安定 | 1次元または単一ボトルネック模型へ縮小 |
| 行動差が見えない | 差が現れる密度・人数領域と検出限界を調べる |
| 計算量が大きい | 空間・人数を縮小し，反復数の根拠を明示 |
| 行動分類が一致しない | 分類基準と観察者間一致を研究中心に変更 |

## 執筆開始の判断

- 基準モデルの分布が得られている．
- 学生独自ルールが1つ動作する．
- 配置の対応と乱数の用途を記録して比較できる．
- 主要指標の不確かさを示せる．
- 実測がなくてもモデル研究として結論を限定できる．
