# 教員用：ステゴサウルス背板と放熱のゴール

:::{warning} 非公開資料
学生用ロードマップに最終的な形状順位を追記しない．本ノートも通常のMyST目次から除外する．
:::

## 卒研としての中心

理想化した皮骨構造の形状差を，同一の物理条件と明示した幾何学的制約のもとで比較し，温度分布と放熱指標の差を数値的に評価する．生物学的機能を断定するのではなく，**放熱仮説に対して形状が持ちうる効果の範囲**を示す．

## 最低成立線

次を満たせば，限定的な2次元数値研究としてまとめられる．

1. 学生用の長方形薄板モデルを再現する．
2. 長方形以外の理想形状を学生が1つ実装する．
3. 2形状を，同じ高さまたは同じ2次元面積のどちらか1条件で比較する．
4. 両形状でエネルギー収支を確認する．
5. 2つ以上の格子幅で総放熱量の変化を確認する．
6. 同一カラースケールの温度場と，総放熱量の表を作る．
7. $h$ または $k$ のどちらか1つについて感度分析を行う．
8. 形状近似と薄板近似の限界を考察する．

学生独自性は，形状定義，正規化条件，評価指標のいずれかに置ける．

## 標準ゴール

- トゲ状，偏平形状，板状など3～4個の理想形状を定義する．
- 同じ高さと同じ体積相当量など，2種類以上の公平性条件を比較する．
- $Q_\mathrm{out}$，体積あたり指標，平均温度，温かい領域割合を比較する．
- 形状差が数値誤差より大きいことを格子収束で確認する．
- $h$, $k$, 厚さ，根元幅のうち2つ以上で感度を調べる．
- 結論が比較条件に依存するかを明示する．

## 発展ゴール

- 連続形態パラメータによる形状系列
- 実際の輪郭データの導入
- 2D FEMによる階段状境界の改善
- 厚さ分布または血流項
- 3Dモデルとの比較

発展項目は標準ゴールの主要図が完成してから着手する．

## 教員が期待してよい定性的傾向

以下は確認すべき仮説であり，学生へ結論として与えない．

- 根元が細い形状では，広い上部へ熱が届きにくい可能性がある．
- $h$ を大きくすると局所放熱は増える一方，形状全体は冷えやすい．
- 総放熱量と材料量あたりの指標では順位が異なりうる．
- 同高さ・同体積などの制約で結論が変わりうる．
- 差が小さい条件領域が存在しうる．

特定形状が必ず優位になることは完了条件にしない．

## 数値的な受け入れ目安

- エネルギー収支：実装誤差が十分小さいこと．基準問題では機械精度に近い一致が望ましい．
- 格子収束：最細2格子の主要指標差を記録し，卒論中で許容理由を説明する．目安として数%以内を目指す．
- 幾何量：正規化対象の相対差を表にし，格子誤差との大小を確認する．
- 単位：すべての入力・出力へ単位を付す．

## 必要な図

1. 形状と境界条件
2. 同一スケールの温度場
3. 格子収束またはエネルギー収支
4. 主指標の形状比較
5. 主要パラメータの感度

## 縮退案

| 問題 | 縮退後の卒研 |
| --- | --- |
| 実形状データが得られない | 理想化した連続形態系列の方法論研究 |
| 複雑形状の格子化が難しい | 長方形・三角形・台形の3形状に限定 |
| 形状順位が格子で変わる | 境界近似と格子誤差の評価を中心課題にする |
| 形状差が小さい | 「差が識別できる物理条件」を感度分析で探す |
| FEMが難しい | 有限体積格子のまま，適用範囲を限定する |

## 執筆開始の判断

- 基準版と研究版コードを分離できた．
- 少なくとも2形状・1公平性条件の結果がある．
- 数値検証図が1枚ある．
- 主結果が予想と異なっても文章で説明できる．
- 発展機能を追加しなくても章構成が成立する．
