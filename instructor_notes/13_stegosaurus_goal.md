# 教員用：ステゴサウルス背板と放熱のゴール

:::{warning} 非公開資料
学生用ロードマップに最終的な形状順位を追記しない．本ノートも通常のMyST目次から除外する．
:::

## 卒研としての中心

理想化した皮骨構造の形状差を，同一の物理条件と明示した幾何学的制約のもとで比較し，温度分布と放熱指標の差を数値的に評価する．生物学的機能を断定するのではなく，**放熱仮説に対して形状が持ちうる効果の範囲**を示す．

## 最低成立線

次を満たせば，限定的な2次元数値研究としてまとめられる．

1. 長方形薄板モデルを再現し，左右・先端断熱の条件で1次元解析解との一致を確認する．
2. 長方形以外の理想形状を学生が1つ実装する．
3. 2形状を，固定する量の組を明記して比較する．たとえば高さ・厚さ・板面積を共通にし，根元幅が変わるかも記録する．
4. 両形状でエネルギー収支を確認する．
5. 少なくとも3段階の格子幅で総放熱量の変化を確認し，形状間差との大小を評価する．
6. 同一カラースケールの温度場と，総放熱量の表を作る．
7. $h$ または $k$ のどちらか1つについて感度分析を行う．
8. 形状近似と薄板近似の限界を考察する．斜めの階段状外周をそのまま辺の合計長で対流させず，外周断熱の限定モデルまたは輪郭に適合した境界処理を採用する．

学生独自性は，形状定義，正規化条件，評価指標のいずれかに置ける．

## 標準ゴール

- 薄板近似を共通に適用できる3～4個の平面輪郭，または連続形態系列を定義する．3次元のトゲとの比較は別の発展課題とする．
- 同じ高さと同じ体積相当量など，2種類以上の公平性条件を比較する．
- $Q_\mathrm{out}$，体積あたり指標，平均温度，温かい領域割合を比較する．
- 形状差が数値誤差より大きいことを格子収束で確認する．
- $h$, $k$, 厚さ，根元幅のうち2つ以上で感度を調べる．
- 結論が比較条件に依存するかを明示する．

## 発展ゴール

- 連続形態パラメータによる形状系列
- 実際の輪郭データの導入
- 2D FEMによる階段状境界の改善
- 厚さ分布または血流項
- 3Dモデルとの比較

発展項目は標準ゴールの主要図が完成してから着手する．

## 教員が期待してよい定性的傾向

以下は確認すべき仮説であり，学生へ結論として与えない．

- 根元が細い形状では，広い上部へ熱が届きにくい可能性がある．
- 根元温度一定で $h$ を大きくすると総放熱量は増え，板内温度は下がる．局所放熱密度は $h$ と温度差の積なので，位置によっては減る．
- 総放熱量と材料量当たりの指標では順位が異なりうる．ただし同体積の比較では両者の順位は同じになる．
- 同高さ・同体積などの制約で結論が変わりうる．
- 差が小さい条件領域が存在しうる．

特定形状が必ず優位になることは完了条件にしない．

## 数値的な受け入れ目安

- エネルギー収支：離散系の保存則が満たされること．基準問題では機械精度に近い一致が望ましいが，連続解への近さを保証しない．
- 格子幅依存性：3段階以上で傾向を調べ，最細2格子の主要指標差を記録する．一律に数%を許容せず，検出したい形状差に対して十分小さいことを確認する．細分化による変化量は厳密な誤差上限ではない．
- 境界近似：階段状外周の長さは，格子細分化だけでは斜めの輪郭長に収束しない．この系統誤差は熱収支検査でも検出できない．
- 幾何量：正規化対象の相対差を表にし，格子誤差との大小を確認する．
- 単位：すべての入力・出力へ単位を付す．

## 必要な図

1. 形状と境界条件
2. 同一スケールの温度場
3. 解析解比較，格子幅依存性，エネルギー収支を区別した検証図表
4. 主指標の形状比較
5. 主要パラメータの感度

## 縮退案

| 問題 | 縮退後の卒研 |
| --- | --- |
| 実形状データが得られない | 理想化した連続形態系列の方法論研究 |
| 複雑形状の格子化が難しい | 長方形・三角形・台形の3形状に限定 |
| 形状順位が格子で変わる | 境界近似と格子誤差の評価を中心課題にする |
| 形状差が小さい | 差を識別できる精度とパラメータ範囲を明記し，明瞭な差がない結果もまとめる |
| FEMが難しい | 両面対流と外周断熱の有限体積モデルに限定し，その仮定のもとで比較する |

## 執筆開始の判断

- 基準版と研究版コードを分離できた．
- 少なくとも2形状・1公平性条件の結果がある．
- 数値検証図が1枚ある．
- 主結果が予想と異なっても文章で説明できる．
- 発展機能を追加しなくても章構成が成立する．
