# 教員用：ヘビ模様と反応拡散のゴール

:::{warning} 非公開資料
最適パラメータや対象画像に対する適合結果は学生用教材へ掲載しない．
:::

## 卒研としての中心

反応拡散モデルが生成する模様と対象画像を，再現可能な前処理と特徴量によって比較する．目的は成因の証明ではなく，**選んだモデルと特徴量が実画像のどの性質を説明でき，どこを説明できないか**を明らかにすることである．

## 最低成立線

1. Gray--Scott基準計算を再現し，数値安定条件を確認する．
2. 利用条件を確認した対象画像を少数用意する．
3. 切り出し，解像度，二値化の手順を固定する．
4. 面積比・成分数・特徴波長のうち1つを選び，人工画像で検証する．
5. 実画像側の特徴量ばらつきを示す．
6. 粗いパラメータ格子で生成模様の特徴量を計算する．
7. 複数seedでシミュレーション側のばらつきを確認する．
8. 近い候補と遠い候補を比較し，モデルの限界を述べる．

画像枚数が少ない場合，個体一般の結論ではなく，対象画像群に限定した方法論研究として位置づける．

## 標準ゴール

- 同一種・同一部位など条件をそろえた複数画像を用いる．
- 2～3個の特徴量を個別に検証する．
- 観測ばらつきで規格化した比較指標を設計する．
- パラメータ空間を粗探索し，有望領域のみ細かく調べる．
- 推定用画像と検証用画像を分ける．
- 最良1点だけでなく，同程度の候補領域を示す．
- 前処理・閾値・seedに対する感度を調べる．

## 発展ゴール

- 縞方向，自己相関，形状記述子の追加
- 別の反応拡散モデルとの比較
- 成長する領域または曲面上のモデル
- ベイズ推定やApproximate Bayesian Computation
- 複数種・複数部位の階層的比較

## 教員が期待してよい定性的傾向

- 1つの特徴量だけでは異なる模様を区別できない場合が多い．
- 複数のパラメータ組が似た特徴量を生む非一意性が起こりうる．
- 二値化閾値は面積比と成分数へ強く影響しうる．
- 画像の平行移動にはFFTパワーが比較的頑健でも，回転・切り出しには注意が必要である．
- 実画像の全特徴を単一の反応拡散モデルが同時に説明できない可能性がある．

適合の成功を完了条件にせず，説明できない特徴の特定も成果とする．

## 受け入れ目安

- 画像の出典・利用条件・前処理手順が追跡可能である．
- 特徴量を手計算可能な人工例で検証している．
- 反応拡散計算の時間刻みを小さくして主要特徴が保たれる．
- 各パラメータ条件を複数seedで評価している．
- 探索範囲と刻みを結果を見る前に記録している．
- 特徴量の単位または無次元化を説明できる．

## 必要な図

1. 元画像と前処理結果
2. 人工画像による特徴量検証
3. 実画像特徴量の分布
4. パラメータ空間の特徴量地図
5. 候補模様と実画像の特徴量比較

## 縮退案

| 問題 | 縮退後の卒研 |
| --- | --- |
| 画像利用許可が得られない | 公開データまたは教員作成人工画像で特徴量手法を評価 |
| 個体数が少ない | 対象画像に限定したケーススタディとして明示 |
| パラメータ探索が重い | 格子・反復数を縮小し，1特徴量の粗探索に限定 |
| 適合候補が見つからない | 実画像がモデルの生成範囲外であることを特徴空間で示す |
| 特徴量が不安定 | 前処理・特徴量の頑健性評価を中心課題にする |

## 執筆開始の判断

- 画像処理手順が固定されている．
- 少なくとも1特徴量の検証が完了している．
- 実画像とシミュレーションの両方に同じ特徴量を適用できる．
- 粗探索の全条件が再生成できる．
- 適合の成否にかかわらず考察できる比較図がある．
