# 教員用：物語の関係変化とネットワークのゴール

:::{warning} 非公開資料
実在人物を対象にしない．対象作品の解釈と数理モデルの推定結果を区別する．
:::

## 卒研としての中心

創作作品または仮想データを対象に，人物間関係を再現可能な規則で時系列化し，単純な基準モデルと必要最小限の拡張モデルを比較する．複雑な感情を客観的に測定できたと主張するのではなく，**定義した指標の範囲で関係変化をどこまで記述できるか**を調べる．

## 最低成立線

1. 作品・人物・場面範囲・時間単位を固定する．
2. 状態値の根拠となるアノテーション基準を作る．
3. 少数場面を再評価し，基準の再現性を確認する．
4. 主要2人について線形または離散的な基準モデルを作る．
5. 観測時系列と基準モデルの残差を示す．
6. 残差に根拠を持つ拡張を1つだけ追加する．
7. 基準モデルと拡張モデルを同じ指標で比較する．
8. 推定に使わない場面または感度分析で検証する．

3人ネットワークまで進めなくても，アノテーション設計と2人基準モデルの検証が十分なら限定的な卒論として成立しうる．

## 標準ゴール

- 3人程度の主要人物を対象にする．
- 有向な人物間状態または頂点状態を明確に選ぶ．
- 複数評価者または再評価によりアノテーションの信頼性を確認する．
- 2人基準モデルと3人拡張モデルを比較する．
- 第三者効果または外部イベントのどちらか一方を追加する．
- 前半場面で推定し，後半場面で検証する．
- 係数の感度と識別可能性を確認する．

## 発展ゴール

- 4人以上の群像ネットワーク
- 複数種類の関係状態
- 時変ネットワーク
- 正則化を伴うパラメータ推定
- 複数作品の比較
- アノテーション不確かさを含む推定

## 教員が期待してよい定性的傾向

- アノテーション基準を細かくしすぎると一致率が下がりうる．
- 係数を増やすほど学習データへの誤差は下がるが，検証性能は改善しない場合がある．
- 複数の係数组が似た時系列を生む識別不能性が起こりうる．
- 外部イベントと人物間係数が代替的に説明してしまう可能性がある．
- 単純モデルの残差自体が，物語構造を議論する材料になりうる．

作品に含まれる感情変化を支配する唯一の法則を発見することは完了条件にしない．

## 受け入れ目安

- 対象範囲と除外基準が明記されている．
- 状態値の根拠を場面へ戻って確認できる．
- 同じ場面の再評価または評価者間比較がある．
- パラメータ数が観測点数に対して過大でない．
- 推定用と検証用のデータを分けている．
- 初期値，尺度，対象場面を変えた感度を確認している．

## 必要な図

1. 人物，時間単位，アノテーション尺度
2. 観測された状態時系列
3. 2人基準モデルの予測と残差
4. 1つの拡張を加えた比較
5. 未使用場面または感度分析での検証

## 縮退案

| 問題 | 縮退後の卒研 |
| --- | --- |
| アノテーション一致が低い | 尺度設計と信頼性評価を中心課題にする |
| 時系列点が少ない | 係数を共通化し，2人・低次元モデルへ縮小 |
| 係数が識別できない | 識別可能性とモデル縮約を中心にする |
| 3人モデルが複雑すぎる | 2人基準モデル＋外部イベント1種に限定 |
| 検証誤差が改善しない | 複雑化が有効でないという比較結果として考察 |

## 執筆開始の判断

- アノテーション基準と対象範囲が固定されている．
- 基準モデルの予測と残差がある．
- 学生独自の拡張が1つだけ実装されている．
- 基準・拡張を同じデータ分割と指標で比較できる．
- 推定値を人物の実在的感情と同一視しない記述ができる．
