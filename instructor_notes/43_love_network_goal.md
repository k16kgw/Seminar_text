# 教員用：物語の関係変化とネットワークのゴール

:::{warning} 非公開資料
実在人物を対象にしない．対象作品の解釈と数理モデルの推定結果を区別する．
:::

## 卒研としての中心

創作作品または仮想データを対象に，定義した状態・観測規則の下で，低次元モデルの記述力と限界を検証する．作品の評価尺度を使う研究のほか，線形ネットワークの過渡応答の比較，既知の仮想データによる係数推定の検証も選べる．複雑な感情を客観的に測定できたと主張しない．

Strogatzの復習として固有値と軌道を表示するだけでは卒研として薄い．比較条件の設計，厳密解による検証，識別可能性または過渡応答の分析，結果の限界まで加えれば，線形系を主題としても学部4年生に適切である．全6状態や非線形化を必須にはしない．

## 最低成立線

1. 作品・人物・場面範囲・時間単位を固定する．
2. 状態値の根拠となるアノテーション基準を作る．
3. 少数場面を再評価し，基準の再現性を確認する．
4. 主要2人について線形または離散的な基準モデルを作る．
5. 観測時系列と基準モデルの残差を示す．
6. 研究の問いに応じて1つの比較を設計する．残差に根拠があれば拡張を1つだけ検討する．
7. 同じ観測点・尺度・予測条件で候補を比較する．
8. 推定に使わない場面での検証と感度分析を行う．仮想データなら独立な初期値や誤差seedでも調べる．

3人ネットワークまで進めなくても，アノテーション設計と2人基準モデルの検証が十分なら限定的な卒論として成立しうる．作品に進まない場合は，明確な比較条件の下で過渡応答を説明する研究や，観測間隔・誤差・励起方向と推定精度の関係を調べる研究を最低成立線にできる．データ収集や拡張の成功そのものを完了条件にしない．

## 数学的・数値的な受け入れ基準

- 2変数の漸近安定条件はトレースが負かつ行列式が正．正の実部があっても安定部分空間上の初期値は収束しうる．
- 純虚数固有値の中心は漸近安定ではない．ゼロ固有値の場合は平衡点の集合とJordan構造を確認する．
- 固有値の実部がすべて負でもノルムの単調減少は保証されない．41の重根の例と42の鎖で一時的増幅を検証できる．
- $A_{ij}$ は $j\to i$ の規約．NetworkXの標準変換には転置が必要で，固有値だけでは全矢印の逆転を発見できない．
- $\alpha>0,\beta\ge0$ なら $s(-\alpha I+\beta A)=-\alpha+\beta s(A)$．基準の循環は $\beta_c=0.8/\sqrt[3]{0.4}$，鎖には有限の臨界値がない．負の辺を含む場合にスペクトル半径を最大実部の代用にしない．
- 数値解は行列指数関数または手計算の解と照合する．`t_eval` の点数を増やすことを積分精度の検証にしない．
- 順序尺度を二乗誤差で適合させるなら間隔の仮定と再符号化への感度が必要．欠測と中立を分ける．
- 3人の有向状態は6状態で，無制約の線形係数行列は6行6列．36係数を少数場面から推定する設計は避ける．
- $\beta A$ の尺度不定性と，単一方向の軌道からの識別不能性を検討する．正則化だけで識別できたとは判断しない．
- 1時点先予測と，将来区間を観測でリセットしない予測を区別する．後から分かった出来事を入力した場合は条件付き再現として報告する．

## 標準ゴール

- 3人程度の主要人物を対象にする．
- 有向な人物間状態または頂点状態を明確に選ぶ．
- 複数評価者または再評価によりアノテーションの信頼性を確認する．
- 2人基準モデルと3人拡張モデルを比較する．
- 第三者効果または外部イベントのどちらか一方を追加する．
- 前半場面で推定し，後半場面で検証する．
- 係数の感度と識別可能性を確認する．

## 発展ゴール

- 4人以上の群像ネットワーク
- 複数種類の関係状態
- 時変ネットワーク
- 正則化を伴うパラメータ推定
- 複数作品の比較
- アノテーション不確かさを含む推定

## 教員が期待してよい定性的傾向

- アノテーション基準を細かくしすぎると一致率が下がりうる．
- 基準を含む入れ子モデルで同じ非正則化の学習損失を大域的に最小化できれば，係数を増やしても最小学習誤差は増えない．ただし実際の最適化や制約の違いには注意し，未使用データの性能は別に確認する．
- 複数の係数组が似た時系列を生む識別不能性が起こりうる．
- 外部イベントと人物間係数が代替的に説明してしまう可能性がある．
- 単純モデルの残差自体が，物語構造を議論する材料になりうる．

作品に含まれる感情変化を支配する唯一の法則を発見することは完了条件にしない．

## 受け入れ目安

- 対象範囲と除外基準が明記されている．
- 状態値の根拠を場面へ戻って確認できる．
- 同じ場面の再評価または評価者間比較がある．
- パラメータ数が観測点数に対して過大でない．
- 推定用と検証用のデータを分けている．
- 初期値，尺度，対象場面を変えた感度を確認している．感度分析を未使用データによる予測検証の代用にしていない．

## 必要な図

1. 人物，時間単位，アノテーション尺度
2. 観測された状態時系列
3. 2人基準モデルの予測と残差
4. 同じ条件でのモデル比較またはネットワーク構造比較
5. 未使用場面または独立な仮想実験での検証と感度分析

## 縮退案

| 問題 | 縮退後の卒研 |
| --- | --- |
| アノテーション一致が低い | 尺度設計と信頼性評価を中心課題にする |
| 時系列点が少ない | 係数を共通化し，2人・低次元モデルへ縮小 |
| 係数が識別できない | 識別可能性とモデル縮約を中心にする |
| 3人モデルが複雑すぎる | 2人基準モデル＋外部イベント1種に限定 |
| 検証誤差が改善しない | 複雑化が有効でないという比較結果として考察 |

## 執筆開始の判断

- アノテーション基準と対象範囲が固定されている．
- 基準モデルの予測と残差がある．
- 独自に設定した問いと，それに答える比較がある．拡張の実装や性能改善は必須にしない．
- 基準・比較対象を同じデータ分割と指標で比較できる．
- 推定値を人物の実在的感情と同一視しない記述ができる．
