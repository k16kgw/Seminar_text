# 卒業研究準備セミナー：数理モデリングとシミュレーション

情報数理学科4年生向けの輪講教材です。学生は Strogatz『Nonlinear Dynamics and Chaos』の輪講を終え、常微分方程式・線形安定性・固有値・相図の基礎を学んでいる一方、偏微分方程式（PDE）は未履修であることを想定しています。

本教材では、既習の「少数の状態変数が時間とともに変わる力学系」から、「空間の各点に状態変数がある力学系」へ進みます。PDEを記号だけで導入せず、偏微分、初期条件・境界条件、拡散方程式、差分法、数値安定性を共通準備で学んでから、4つの卒業研究テーマへ接続します。

## 学習目標

- ODEとPDEの違いを、状態変数・時間・空間の役割から説明できる。
- 拡散方程式の各項、初期条件、境界条件の意味を説明できる。
- 有限差分法で1次元拡散方程式を計算し、刻み幅と安定性の関係を確認できる。
- 現象を状態変数・パラメータ・方程式または更新規則へ翻訳できる。
- 複数テーマに共通する「局所則から全体挙動」「比較条件」「評価指標」を自分の卒業研究へ移せる。

## 学習順序

輪講前に全員が共通準備を行い、その後、4人の学生が1人1回50分を担当します。自分の担当回だけでなく、前の回で導入された考え方を次の回で再利用する順序です。

| 段階 | 担当 | 教材 | 前後のつながり |
| --- | --- | --- | --- |
| 共通準備1 | 全員 | [研究設計と数理モデリングの作法](chapters/00_research_design.md) | 全テーマで使う問い・変数・比較指標をそろえる |
| 共通準備2 | 全員 | [ODEからPDEへ：拡散方程式入門](chapters/00_pde_foundations.md) | PDE、境界条件、差分法をゼロから学ぶ |
| 第1回 | 学生A・50分 | [放熱の基礎](chapters/01_stegosaurus_heat_basic.md) → [形態比較](chapters/02_stegosaurus_heat_shape.md) | 拡散方程式を具体的な熱輸送と形状比較に使う |
| 第2回 | 学生B・50分 | [反応拡散の基礎](chapters/03_reaction_diffusion_basic.md) → [画像との比較](chapters/04_reaction_diffusion_snake.md) | 第1回の拡散に局所反応を加え、空間パターンを扱う |
| 第3回 | 学生C・50分 | [最小CA](chapters/05_agent_boarding_basic.md) → [行動ルール](chapters/06_agent_boarding_behavior.md) | 連続場のPDEと離散個体の局所更新を比較する |

| 振り返り | 全員 | [4つのモデルを卒業研究へ移す](chapters/09_synthesis.md) | 各テーマの知見を自分の研究計画に翻訳する |

## 1回50分の輪講

各担当者は、テーマに対応する2章をすべて説明するのではなく、次の時間配分で「問いから比較結果まで」を1本の物語として発表します。

| 時間 | 内容 |
| ---: | --- |
| 0–5分 | 現象、研究上の問い、前回との接続 |
| 5–15分 | 状態変数、仮定、最小モデル |
| 15–27分 | 方程式または更新規則。式の各項の意味 |
| 27–37分 | Notebookによる比較実験。変えるパラメータは原則1つ |
| 37–44分 | 評価指標で結果を解釈し、モデルの限界を述べる |
| 44–50分 | 質疑と「他テーマ／自分の卒研に移せる考え方」の確認 |

発表前には、全員が該当テーマの前半章を読み、Notebookの標準設定の図を確認します。発表後には、担当者以外も「自分の研究で再利用できる考え方」を1つ記録します。

## Notebook

共通準備と各章に対応する Jupyter Notebook があります。外部データなしで上から実行でき、設定パラメータを上部にまとめています。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Notebookの形式確認：

```bash
python scripts/check_notebooks.py
```

全Notebookの実行確認：

```bash
python scripts/check_notebooks.py --execute
```

## MyST book

ローカルプレビューとHTMLビルドには MyST CLI を使います。

```bash
myst start
myst build --html
```

HTMLは `_build/html` に出力されます。`main` ブランチへのpush時には GitHub Actions がNotebookを確認し、MyST bookをGitHub Pagesへ公開します。

## 科学的な位置づけ

各モデルは、考え方と検証手順を学ぶための教育用最小モデルです。ステゴサウルス背板の機能、動物模様の成因、実際の鉄道運用、実在人物の関係を断定・評価するものではありません。仮定、無視した要因、適用範囲を明示することも輪講の評価対象です。
