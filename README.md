# 卒業研究準備セミナー：数理モデリングとシミュレーション

情報数理学科4年生向けの卒業研究準備教材です．学生は Strogatz『Nonlinear Dynamics and Chaos』を輪講し，常微分方程式・線形安定性・固有値・相図の基礎を学んでいる一方，偏微分方程式（PDE）は未履修であることを想定しています．

本教材の目的は，卒業研究の完成例を先に与えることではありません．基礎モデルを理解し，単純な例で数値計算と評価方法を練習した後，研究の中心となる問い・モデルの拡張・比較実験・検証は学生自身が行います．

## ファイル番号の規則

各テーマでは，末尾 `0` を準備，`1` を基礎モデル，`2` を研究技能，`3` を卒研ロードマップに対応させます．NotebookとNotebook出力図は対応する学生向け章の番号，教員用ゴールは各テーマのロードマップ番号にそろえています．

## 構成方針

各テーマを次の3段階に分けています．

1. **基礎モデル**：教科書的な最小モデルを理解し，標準設定で再現する．
2. **研究技能の練習**：卒研対象そのものではなく，単純・汎用的な例で必要な技法を身につける．
3. **卒研ロードマップ**：学生が自分で決める事項，確認点，段階的な到達目標を示す．最終結果や「正解」は示さない．

教材中のNotebookは，基礎と技能練習までは実行可能な形で用意しています．卒研ロードマップでは完成コードを配布せず，学生がそれまでのNotebookを複製・改造して研究用Notebookへ育てます．

## 卒研の準備

全員が研究設計を読んだ後，4テーマそれぞれの入口を学びます．他テーマの準備章も読むことで，卒研中に使える考え方（空間場，離散更新，確率，行列，固有値）を共有します．

## テーマごとの学習経路

### ステゴサウルス背板と放熱

1. [熱方程式と1次元フィン](chapters/11_stegosaurus_heat_basic.md)
2. [単一薄板の2次元温度場](chapters/12_stegosaurus_heat_shape.md)
3. [卒研ロードマップ：形状比較を研究にする](chapters/13_stegosaurus_research_roadmap.md)

教材では1つの単純形状までを扱います．複数形状の定義，公平な正規化，形状ごとの温度分布・放熱効率比較は学生自身の卒業研究として残します．

### ヘビ模様と反応拡散

1. [反応拡散方程式とパターン生成](chapters/21_reaction_diffusion_basic.md)
2. [模様を数値で測る基礎](chapters/22_reaction_diffusion_snake.md)
3. [卒研ロードマップ：生成模様と実画像を比較する](chapters/23_snake_research_roadmap.md)

教材では反応拡散の実行と，汎用的な模様画像から特徴量を測るところまでを扱います．ヘビ画像の収集，特徴量の選択，損失関数，パラメータ探索は学生自身が設計します．

### 電車乗降とマルチエージェント

1. [最小セルオートマトン](chapters/31_agent_boarding_basic.md)
2. [確率的シミュレーションの検証](chapters/32_agent_boarding_behavior.md)
3. [卒研ロードマップ：行動ルールを比較する](chapters/33_boarding_research_roadmap.md)

教材では基準モデルと，乱数seed・反復実験・ばらつきの扱いまでを学びます．ドア付近の行動分類，代替ルール，実測動画との比較は学生自身が研究します．

### 恋愛モデルとネットワーク

1. [2人の線形ODE](chapters/41_love_dynamics_basic.md)
2. [一般的な3頂点ネットワーク力学](chapters/42_love_dynamics_network.md)
3. [卒研ロードマップ：物語の関係変化をモデル化する](chapters/43_love_research_roadmap.md)

教材では既習の2変数ODEと，一般的なネットワーク結合の読み方までを扱います．作品の選定，感情の定義，アノテーション，第三者効果，パラメータ推定は学生自身が決めます．

## 学習の進め方

基礎・研究技能の各章は，本文の読解，Notebook図の読み取り，短い演習，チェックポイントの順に学ぶ構成です．各章冒頭の「学習ガイド」には，学習内容と到達確認を示しています．卒研ロードマップと最後の振り返りも含め，学生が研究中に繰り返し参照するガイドです．

教員はセミナー時間に応じて演習数を減らせますが，次の順序は保ちます．

```text
予想する → 式を読む → 図を読む → 数値を検証する → 自分の言葉で説明する
```

Notebookの図は章本文にも掲載し，軸，色，曲線，読み取れること，誤読しやすい点を解説しています．学生はNotebookを手元で実行できない場合でも，本文だけで図の意味を追えます．

概念図の編集用元データは，[concept_diagrams_editable.pptx](assets/figures/concepts/concept_diagrams_editable.pptx)にまとめています．文字，箱，矢印，格子点などはPowerPoint上で個別に編集できます．再生成方法は[概念図README](assets/figures/concepts/README.md)を参照してください．

学習速度に応じて，1回に進む章数や扱う発展課題は調整できます．前段階のチェックポイントを満たしてから卒研ロードマップへ進みます．

## Notebookの使い方

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

形式確認：

```bash
python scripts/check_notebooks.py
```

全Notebookの実行確認：

```bash
python scripts/check_notebooks.py --execute
```

実行済みNotebookの代表図を章掲載用に更新：

```bash
python scripts/export_notebook_figures.py
```

Notebookを変更した場合は，全セルを実行してから代表図を書き出し，章本文の説明と一致していることを確認します．

## 科学的な位置づけ

各モデルは，考え方と検証手順を学ぶための教育用最小モデルです．ステゴサウルス背板の機能，動物模様の成因，実際の鉄道運用，実在人物の関係を断定・評価するものではありません．仮定，無視した要因，適用範囲を明示することも学習目標に含みます．
