## この章の目的

Strogatz の **2人恋愛モデル**（Romeo and Juliet モデル）{cite}`strogatz1988love` を復習し、線形2変数ODEの固有値・相図・安定性を恋愛の言葉で読み直す。さらに **外力項** や **飽和項** を加え、物語（ドラマ・アニメ）への応用を考える。

:::{warning} 科学的な注意
本章のモデルは **実在人物の関係を評価するためのものではない**。ドラマ・アニメ・仮想データを対象とした、力学系の教材である。
:::

## 現象の説明

2人の登場人物の「相手への好意」が、時間とともにどう変化するかを考える。一方が好かれると嬉しくて好意を増す人もいれば、逆に引いてしまう人もいる。この「相手の感情への反応の仕方」を係数で表すと、関係の時間変化が連立微分方程式になる。これは第1章までで学んだ線形2変数系そのものである。

## 最小モデル

$R(t)$ をロミオのジュリエットへの好意、$J(t)$ をジュリエットのロミオへの好意とする。各自の好意の変化率を、自分と相手の現在の好意の線形結合で表す。

## 数式による定式化

### 基本モデル

```{math}
:label: eq-rj
\frac{dR}{dt} = aR + bJ,
\qquad
\frac{dJ}{dt} = cR + dJ
```

行列で書くと $\dot{\mathbf{x}} = M\mathbf{x}$、$\mathbf{x}=(R,J)^\top$、$M=\begin{pmatrix}a&b\\c&d\end{pmatrix}$ である。

係数の意味（ロミオの場合）：

- $a>0$：自分の好意が高まると さらに高まる（のぼせ型）。$a<0$：自分の好意は冷めていく（慎重型）。
- $b>0$：相手に好かれると好きになる。$b<0$：相手に好かれると引く（あまのじゃく型）。

### 固有値と安定性

挙動は $M$ の固有値 $\lambda_{1,2}$ で決まる（第00章・Strogatz で学んだとおり）。

```{math}
:label: eq-eig
\lambda = \frac{\mathrm{tr}\,M \pm \sqrt{(\mathrm{tr}\,M)^2 - 4\det M}}{2}
```

- 実固有値で異符号：鞍点（一方は燃え上がり一方は冷める発散）。
- 複素固有値（$(\mathrm{tr}\,M)^2 < 4\det M$）：振動。実部が0なら **渦状（中立的な好き嫌いの周期）**、実部が負なら減衰してすれ違いが収まる。

特に $a=d=0$、$b=-c$ のときは純虚数固有値となり、2人の好意が永遠に周期的に回る「すれ違い続ける関係」になる。

### 外力項付きモデル

物語には外部イベント（誕生日、けんか、ライバル登場）がある。これを時間依存の外力 $F_R(t), F_J(t)$ で表す。

```{math}
:label: eq-rj-force
\frac{dR}{dt} = aR + bJ + F_R(t),
\qquad
\frac{dJ}{dt} = cR + dJ + F_J(t)
```

たとえば $F_R(t)$ をある時刻に立つパルスにすると、「あるエピソードでの出来事」が関係の軌道をどう変えるかを見られる。

### 飽和項付きモデル

線形モデルは好意が無限に発散しうる。現実には感情には上限がある。3次の飽和項を加える。

```{math}
:label: eq-rj-sat
\frac{dR}{dt} = aR + bJ - \lambda R^3,
\qquad
\frac{dJ}{dt} = cR + dJ - \mu J^3
```

飽和項により、発散は有限の平衡（落ち着いた関係）へと抑えられる。線形では鞍点で発散していたものが、非線形では複数の安定平衡（両思い・両片思いなど）に分かれることがある。

## パラメータの意味

| 記号 | 意味 |
| --- | --- |
| $a,d$ | 自分の好意への反応（のぼせ／慎重） |
| $b,c$ | 相手の好意への反応（応える／引く） |
| $F_R,F_J$ | 外部イベント（外力） |
| $\lambda,\mu$ | 感情の飽和の強さ |

## 数値シミュレーション

Notebook では次を行う（seed 固定は外力にノイズを入れる場合のみ）。

1. 係数 $a,b,c,d$ を設定する。
2. ODE を `scipy.integrate.solve_ivp` で数値積分する。
3. 時系列 $R(t), J(t)$ をプロットする。
4. 相平面 $(R,J)$ に軌道とベクトル場を描く。
5. ある時刻に外力パルス {eq}`eq-rj-force` を加え、軌道の変化を見る。
6. 係数を変えて、鞍点型・渦状・減衰型を比較する。

:::{note} 評価指標
評価指標は **固有値**（$\lambda_{1,2}$ の実部・虚部）と **相図の型**（鞍点／渦／焦点）である。時系列の形を固有値で説明できるようにすること。
:::

## 卒業研究への接続

- ドラマやアニメの各話に「このエピソードで好意が上がった/下がった」というアノテーションを付け、外力 $F(t)$ として与えると、モデルと物語を対応づけられる。
- 係数 $a,b,c,d$ を時系列データから推定すれば、「この2人はのぼせ型か慎重型か」を定量化できる。
- 第8章では2人から複数人へ拡張し、三角関係・群像劇を扱う。
- 共通準備でPDEを空間差分すると大きな連立ODEになったのと同様に、人物を増やすと状態ベクトルが高次元になる。違いは、結合が物理空間の隣接ではなく人物関係で決まる点である。

## 演習問題

1. **（理論）** $a=d=0$、$b=1$、$c=-1$ のとき固有値 {eq}`eq-eig` を求め、相図が渦になることを示せ。2人の好意はどんな時間変化をするか。
2. **（数値）** Notebook で鞍点型（$\det M < 0$）と安定焦点型（$\mathrm{tr}\,M<0$, 複素固有値）の係数をそれぞれ選び、時系列と相図を比較せよ。
3. **（数値）** 外力パルス {eq}`eq-rj-force` を入れる時刻を変えると、最終的な関係（落ち着く／別れる）が変わるか調べよ。

## 発展課題

- 飽和項付きモデル {eq}`eq-rj-sat` で、線形では発散した係数でも有限平衡に落ち着くことを確認せよ。平衡点はいくつあるか。
- 外力を周期的（$F_R(t)=A\sin\omega t$）にし、共鳴的に好意が増幅される $\omega$ があるか調べよ。
