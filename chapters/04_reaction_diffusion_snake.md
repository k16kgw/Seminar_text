# 第4章　ヘビ模様の反応拡散 II：写真画像との比較とパラメータ探索

:::{tip} 対応 Notebook
[04_snake_pattern_features.ipynb](../notebooks/04_snake_pattern_features.ipynb)
:::

## この章の目的

第3章で生成した反応拡散パターンを、**実際のヘビ写真と比較するための考え方** を学ぶ。鍵は「ヘビっぽい」という主観をやめ、**特徴量** で定量的に比較することである。さらに、特徴量を合わせるための **パラメータ探索** の枠組みを理解する。

## 現象の説明

反応拡散モデルは斑点や縞を作れる。では「このパラメータで作った模様は、このヘビに似ているか」をどう判断するか。人間が並べて「似ている」と言うだけでは研究にならない。**同じ量で測って数値で比べる** 必要がある。

:::{warning} 科学的な注意
実際のヘビ模様は、反応拡散だけでなく **遺伝・発生・成長・鱗構造・環境** の影響を受ける。また写真には **個体差・撮影角度・照明・曲面（体の丸み）** の影響が入る。本章の比較は「特徴量がどれだけ近いか」を測るものであり、「反応拡散がヘビ模様の原因だ」と結論づけるものではない。
:::

## 最小モデル

画像（実写真でも生成パターンでも）を、**少数の特徴量ベクトル** に圧縮し、その距離で比較する。Notebook は外部画像がなくても動くよう、擬似的な模様画像を生成して使う。`assets/data/` に画像を置けば差し替えられる構造にする。

## 数式による定式化

### 画素ごとの単純比較（ナイーブ）

最も素朴な比較は、画像同士の画素差である。

```{math}
:label: eq-pixel
L(\theta) = \big\| I_\mathrm{snake} - I_\mathrm{sim}(\theta) \big\|^2
```

$\theta$ はモデルのパラメータ（$F,k,D_u,D_v$ など）、$I_\mathrm{sim}(\theta)$ は生成画像である。しかしこれは **位置ずれ・回転・位相のずれに極端に弱い**。模様の「柄」が同じでも、斑点の位置が1つずれれば $L$ は大きくなる。模様の比較には不向きである。

### 特徴量による比較

そこで、位置に依存しない特徴量で比較する。

```{math}
:label: eq-feature
L(\theta) = w_1\,\big|r_\mathrm{area} - \hat r_\mathrm{area}\big|
          + w_2\,\big|\lambda - \hat\lambda\big|
          + w_3\,\big|n_\mathrm{spot} - \hat n_\mathrm{spot}\big|
```

ここで

- $r_\mathrm{area}$：二値化後の **暗部面積比**（模様が占める割合）。
- $\lambda$：模様の **特徴波長**（縞や斑点の間隔。FFT から推定）。
- $n_\mathrm{spot}$：**連結成分数**（斑点の個数）。

ハット付きは実画像から測った目標値、$w_i$ は重みである。これらは平行移動・小さな回転に対してほぼ不変なので、画素比較より頑健である。

## 特徴量の作り方

| 特徴量 | 計算法 | 何を捉えるか |
| --- | --- | --- |
| 面積比 $r_\mathrm{area}$ | 二値化して暗部の割合 | 模様の濃さ |
| 斑点数 $n_\mathrm{spot}$ | 連結成分ラベリング | 斑点か縞か |
| 特徴波長 $\lambda$ | 2D FFT の放射平均のピーク | 模様の細かさ |
| 方向性 | FFT スペクトルの角度分布 | 縞の向き |
| 空間自己相関 | 自己相関関数の減衰 | 規則性の強さ |

二値化には大津の方法（`skimage.filters.threshold_otsu`）、連結成分には `skimage.measure.label` を使う。

## パラメータの意味

比較の目的は「実画像の特徴量 $(\hat r_\mathrm{area}, \hat\lambda, \hat n_\mathrm{spot})$ に近い模様を出す $(F,k)$ を探す」ことである。特徴波長 $\lambda$ は主に拡散係数と格子間隔で決まり、斑点／縞の別は $(F,k)$ で決まる。したがって探索は段階的に行う。

1. $\lambda$（細かさ）を拡散比でおおまかに合わせる。
2. $(F,k)$ を変えて斑点数・面積比を合わせる。

## 数値シミュレーション

Notebook では次を行う（外部画像不要）。

1. ターゲットとして、既知パラメータの反応拡散パターン（または `make_placeholder_assets.py` の擬似模様）を生成する。
2. グレースケール化 → 二値化 → 面積比・連結成分数を計算する。
3. 2D FFT の放射平均から特徴波長 $\lambda$ を推定する。
4. 別の $(F,k)$ で候補パターンを生成し、特徴量距離 {eq}`eq-feature` を計算する。
5. 数点の $(F,k)$ について距離を比べ、最も近い候補を選ぶ（粗いグリッド探索）。

:::{note} 評価指標
この章の評価指標は **特徴量距離 $L(\theta)$**（式 {eq}`eq-feature`）である。画素差 {eq}`eq-pixel` がなぜ使えないかを必ず1度は自分で確認すること。
:::

## 卒業研究への接続

- 特徴量を増やし（自己相関長、方向ヒストグラム等）、距離 {eq}`eq-feature` の重み $w_i$ を調整する設計は、そのまま卒研の中心になる。
- グリッド探索を最適化（ベイズ最適化、CMA-ES 等）に置き換えれば、より広い $(F,k)$ 空間を探索できる。
- 実写真を使う場合、前処理（曲面補正・照明補正・トリミング）の良し悪しが結果を左右する。前処理パイプラインの比較も研究になる。

## 演習問題

1. **（実験）** Notebook で、同じ模様を1ピクセル平行移動した画像を作り、画素差 {eq}`eq-pixel` と特徴量距離 {eq}`eq-feature` がそれぞれどれだけ変わるかを比べよ。なぜ画素差は模様比較に不向きか説明せよ。
2. **（数値）** 3〜5通りの $(F,k)$ で模様を生成し、面積比・斑点数・特徴波長を表にまとめよ。ターゲットに最も近いのはどれか。
3. **（考察）** 実際のヘビ写真を比較に使うとき、特徴量を歪める要因を3つ挙げ、それぞれの対策を述べよ。

## 発展課題

- `assets/data/` に自分で用意したヘビ写真（または模様画像）を置き、特徴量を測ってターゲットにせよ。
- 方向性（縞の向き）を特徴量に加え、縞模様のヘビと斑点模様のヘビを区別できるか確かめよ。
