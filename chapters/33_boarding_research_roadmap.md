# 卒研ロードマップ：行動ルールを比較する

## この章の目的と卒業研究の到達点

[31章](./31_agent_boarding_basic.md)で検証した基準モデルに，自分で定義した行動ルールを加え，[32章](./32_agent_boarding_behavior.md)の方法で反復比較する．目標は，指定した条件の下で行動ルールが何を変え，どの条件では変えないかを，検証可能な形で示すことである．特定の行動が必ず有利になることや，実際の鉄道運用への推奨を得ることを完了条件にしない．

大学4年生の卒業研究としては，基準コードの再実行だけでなく，ルールの操作的定義，小配置での検証，対応を管理した反復実験，効果の不確かさ，限界の考察を自分で行う．最初は代替ルール1つと主評価量1つでよい．多数の行動，複雑な最適化，高度な動画処理を同時に導入する必要はない．

| 段階 | 判断・実装する内容 | 残す成果 |
| --- | --- | --- |
| 基準検証 | 人数，排他則，距離，終了判定 | 小配置テストと正常・停止の例 |
| 問い | 誰が，いつ，どこへ移るか | 操作的な定義と適用範囲 |
| 独自実装 | 発動，候補，競合，復帰，完了 | 基準との変更点と単体テスト |
| 実験設計 | 比較単位，配置，乱数，上限，反復数 | 再実行できる実験条件表 |
| 評価 | 完了率，時間差，局所占有 | 差とばらつきの図・表 |
| 検証・考察 | 未使用配置，人数や空間の感度 | 根拠を限定した結論 |

## 観察可能な問いへ絞る

協力的な行動や迷惑な行動という評価語ではなく，位置・方向・時間で判定できる問いにする．たとえば，ドア近傍で横方向への移動を許す条件を変えると，対向流の未完了率と移動完了時間がどう変わるか，という形式である．

次をあらかじめ定める．

- 行動の対象者は誰か．乗車客，降車客，乗降しない滞留者を区別する．
- 発動を判断する観測領域はどこか．ドアからの距離，近傍の占有，待ち時間などで定義する．
- 行動の有無で変えるものは何か．候補方向，開始時刻，優先度などを分ける．
- 完了とは何か．ドア通過，領域端への到達，再乗車までの完了を区別する．

31章の固定障害物はセルを通行不能にしたものであり，判断して移動する滞留者ではない．固定障害物を消す操作を，人が横へ移動したことと同一視しない．人として比較するなら，元の占有セルから新しいセルへの移動と人数保存を実装する必要がある．

## 観察記録とモデル規則を分ける

![観察から更新規則を作り，反復比較へ進む研究の流れ．](../assets/figures/concepts/boarding_research_pipeline.png)

図の段階ごとに，直接観測した事実と解釈を分けて記録する．

| 記録 | 内容の例 |
| --- | --- |
| 観察記録 | ある時刻にドアから一定距離の位置へ移った |
| 行動ラベル | 定めた位置・時間条件に基づいて横移動と分類した |
| モデル規則 | 条件を満たした個体が指定方向の空セルを候補にする |

動画では体の向きや意図を確実に読み取れない場合がある．曖昧例，遮蔽，画面外の個体は分類不能として残し，見えない意図を断定しない．複数の観察者が同じ基準で分類した一致率や食い違いの表を作ると，分類の再現性を検討できる．

実動画を使わない研究も可能である．その場合は観測された行動ではなく，理想化した仮想ルールの比較であると明記する．先行研究や観察から着想した部分と，自分で置いた仮定を区別する．モデルの記述項目を整理するには，目的，状態，更新順序，初期化などを記述するODDの枠組みも参考になる．[Grimmらの原論文](https://www.jasss.org/23/2/7.html)は，規則と仮定を他者が再構成できるよう記録するための指針である．

## 基準モデルと独自ルールの検証

### 基準の仮定を固定する

31章では，一斉更新，壁を避ける静的な最短距離，距離を減らす移動だけを採用した．一方向流の完了は検証できるが，対向流は永久停止しうる．これをコードの誤りと，理想化した規則の限界に分けて扱う．単に上限を増やして停止問題を解消したと考えない．

基準版を保存し，空間，人数，初期配置，距離場，競合規則，境界，開始・終了条件を表にする．変更後も1人の経路，競合する2人，壁際の個体，人数0，配置可能人数の上限などの検証を実行する．実装が規則どおりかの検証と，規則が実際の乗降を表すかの検証は別である．

### 代替ルールを状態遷移として書く

発動条件，候補セル，同順位の選択，空きがない場合，終了・復帰条件を文章と擬似コードで定める．必要なら個体に追加状態を持たせる．一時的に領域外へ出る場合は，外側で待つ状態，再び入る状態，最終完了の状態を区別する．

```text
対象者と発動条件を判定する
更新前の状態から移動候補を作る
通常移動と追加行動を合わせて競合を解決する
全員の確定した移動を反映する
復帰・完了の条件を判定し，人数と重複を検査する
```

通常移動の後で横移動を追加して，同じ個体を1ステップに2セル進めてしまわないようにする．1ステップ1セルの仮定を変えるなら，時間尺度も含めて変更として記録する．占有したセルを空けたことにするだけの確率パラメータでは，移動先の占有と人数の整合性を表せない．

元の位置へ戻る行動を扱う場合，そのセルが既に他者で埋まっている可能性がある．何を待ち，どの空間を通って戻るのかも規則に含める．車外へ一時的に出た人を完了者として消すと，元の人数条件と違う実験になる．

### 不変量とデッドロック判定を更新する

乗降しない滞留者や一時退出者を人として追加した場合は，人数保存を

```{math}
N_{\rm active}+N_{\rm outside\ waiting}+N_{\rm finished}=N_{\rm total}
```

のように，互いに重複しない状態区分で定める．どの状態も数え落とさず，二重にも数えない．

31章の早期デッドロック判定は，全員に距離を減らす候補がなく，他の変化が起きないという仮定に依存する．横移動や待ち時間に応じた行動，確率的な再試行を加えたら，止まっていても後で動く可能性がある．その場合は遷移規則から吸収性を証明するか，単に共通上限までの未完了として記録する．一定回数動かなかったという経験則だけで永久停止と断定しない．

## 比較の単位と乱数を設計する

### 初期配置を保存して対応付ける

同じ人数と幾何形状で基準と代替を比べるなら，各反復の初期配置を1回生成して保存し，両条件に複製する．初期配置用，行動者割当用，移動・競合用の乱数を分離する．`seed` が同じでも，初期化処理や乱数の消費順が違えば同じ配置にはならない．

固定障害物の有無を比較する場合は，障害物を置く候補セルに人が初期配置されないよう，両条件で共通の配置可能集合を使う方法がある．この制約によって初期配置分布がどう変わったかも明示する．人数や領域そのものを変える比較では，完全に同じ配置は不可能なので，共通化できる人の位置や配置生成法を定める．

時刻ごとの共通乱数が有効な場合もあるが，別の規則では別の出来事が起こる．同じ乱数が何に対応するかを説明できなければ，単に同じseedで分散が減るとは主張しない．独立な更新乱数を使う比較も可能であり，実験の対応関係に合う集計を選ぶ．

### 独立な反復単位を決める

新しい初期配置を作った試行を独立な反復の単位にするのか，1つの配置の下で更新乱数を変えるのかを決める．両方を調べるなら配置IDと配置内反復IDを保持する．同じ配置の反復をすべて独立な配置と数えず，配置ごとの平均差を使うなど，集計の階層を保つ．

1本のシミュレーションに含まれる時刻や個体は相互作用するため，独立な標本数にはならない．実動画でも，同じ乗降場面から切り出した複数区間を独立な列車・駅の標本とみなしてはいけない．

## 主評価量と未完了の扱いを先に決める

完了時刻の定義をそろえ，共通の上限 $C$ を決める．モデルの移動完了時刻を，実際の扉開閉を含む停車時間と呼ばない．一時退出者を含めた再乗車までを完了とするなら，基準条件と代替条件で同じ対象者を数える．

| 評価量 | 定義・注意 |
| --- | --- |
| 完了率 | $\Pr(T\le C)$ を全試行から推定する |
| 上限制限平均 | $E[\min(T,C)]$ を共通上限で比較する |
| 完了時刻分布 | 未完了の有無を示す．完了例だけなら条件付き分布と呼ぶ |
| 局所密度 | 同じ領域・面積・観測時刻で比較する |
| 競合数 | 希望先の競合であり，現実の接触事故ではない |
| 個体別停止時間 | どの状態を待機と数えるかを決める |
| 移動距離 | 1移動当たりの距離と，一時退出・復帰を含むかを決める |

失敗しやすいルールでも，速く終わる少数の試行だけの平均は短くなりうる．未完了を削除せず，完了率と $Y=\min(T,C)$ を併記する．デッドロックを早期に証明した場合は $Y=C$ とし，その検出時刻を完了時刻の代わりに使わない．

時間平均密度も観測窓で意味が変わる．各試行の完了までで平均した量と，共通時刻 $C$ までで平均した量は異なる．前者は完了時間に応じて分母が変わり，後者は完了後を空とするため，早い完了も値を小さくする．問いに合う定義を選び，図の色範囲もそろえる．

## 対応差と不確かさを示す

反復 $r$ ごとに基準と代替の上限制限時間の差

```{math}
\Delta_r=Y_{r,\rm alt}-Y_{r,\rm base}
```

を作り，平均差と $s_\Delta/\sqrt n$ を求める．差が負なら代替の方が短い．完了率の差は，各試行の完了指標の差 $\delta_{r,\rm alt}-\delta_{r,\rm base}$ から集計できる．基準だけが完了，代替だけが完了，両方完了，両方未完了の4分類も示すと，平均差だけでは見えない変化を追いやすい．

同じ初期配置を結ぶ点の図，差の分布，近似信頼区間を示す．差が統計的に明瞭かに加え，何ステップの差で，移動距離や未完了率がどれだけ変わるかという実質的な大きさを述べる．多くの条件を試して最も有利なものだけを報告すると，偶然に大きな差が出た条件を選びやすい．探索用の配置集合と，結論を確認する未使用の配置集合を分ける．

反復数は一律に100回などと決めず，予備計算で差のばらつきを測り，必要な精度に基づいて本計算の回数を決める．小さい差しかなく，区間が広い場合は，差がないと断定するのではなく，今の精度では区別できないと述べる．

## 行動を取る割合を研究変数にする

32章の通過確率 $p$ と区別し，行動者の割合を $\alpha$ とする．対象者が $N_s$ 人いるとき，次の2方式は異なる実験である．

- 固定人数方式：$K=\lfloor\alpha N_s+1/2\rfloor$ 人を選ぶ．実現割合は $K/N_s$ である．
- 独立割当方式：各人を確率 $\alpha$ で選ぶ．行動者数は $K\sim\operatorname{Binomial}(N_s,\alpha)$ となる．

後者では $E[K]=\alpha N_s$，分散は $N_s\alpha(1-\alpha)$ であり，行動者数自体も揺らぐ．前者では人数が少ないと，異なる $\alpha$ が同じ $K$ に丸められる．指定割合だけでなく実現した人数と配置も保存する．

割合を増やすときの対応を保つなら，各反復で対象者の無作為な順位を1つ作って先頭 $K$ 人を選ぶ，または個体ごとの一様乱数 $U_i$ を固定して $U_i<\alpha$ の人を選ぶ方法がある．条件ごとに無関係に選び直す方式との違いを説明する．1試行中に毎ステップ選び直す方式は，固定した行動特性を持つ集団とは別のモデルである．

最初は粗い割合で調べ，単調な改善を仮定しない．中間割合で競合が増えたり，未完了率と完了例の時間が逆方向に変化したりする可能性もある．

## 感度分析と実測への接続

主比較を固定してから，人数，乗降比，ドア幅，滞留者位置，更新方式を順に変える．1要因ずつの比較は原因を追いやすいが，要因間の相互作用を見落とす．主要な2要因について小さな格子状の条件表を作り，人数が多いときだけルール差が現れるかなどを確認する．

格子幅を小さくする場合は，人の占有面積，最大速度，ドアの実幅をどう保つか定義する．1人1セルのままで細分化すると別の物理モデルになる．一斉更新と逐次更新の違いも，単に計算誤差を小さくする操作ではなくモデル仮定の変更である．

実動画を使う場合は利用条件，必要な許可，匿名化，保存範囲を確認する．人数やドア幅など直接測れる量を先に定め，行動パラメータと時間換算を同時に自由に調整しすぎない．画像から測る密度や完了時刻の範囲をモデルと対応させる．

推定用と検証用の動画は，元の乗降場面や撮影単位が重ならないように分ける．同じ動画の別区間だけで検証しても，別の場面への一般性は十分には分からない．観測誤差，場面差，乱数による変動，モデル仮定の不足を分けて考察する．実測への一致だけで行動の因果効果が証明されたとはしない．

## 成果物と結論の範囲

- 空間・状態・更新順序と独自ルールの変更点を示す図．
- 小配置と人数保存・排他則・終了判定の検証結果．
- 基準と代替の全試行表，対応差，完了率と未完了の内訳．
- 行動割合または主要条件に対する応答と不確かさ．
- 未使用配置と感度分析での再確認．
- 問いへの答え，適用条件，説明できない点をまとめた文章．

同じ平均でも分布や未完了率が異なれば，どちらが優れるかは評価基準に依存する．モデル内での改善を，現実の人に対する行動推奨へ飛躍させない．最終発表では[研究成果のまとめ方](./50_synthesis.md)に沿って，問い，方法，結果，考察を対応させる．

実動画が得られない場合は，仮想ルールの比較と感度分析に限定できる．計算が重ければ条件数や自由パラメータを減らし，必要な反復と検証は残す．差が見えない場合も，検出できる差の大きさや，どの条件では区別できないかを示せる．基礎模型の理論分布を再現するだけで終わらず，自分の問いに対する追加実験と考察を含める．
