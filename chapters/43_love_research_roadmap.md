# 卒研ロードマップ：物語の関係変化をモデル化する

:::{important} この章の役割
[2人の線形ODE](./41_love_dynamics_basic.md)と[ネットワーク力学](./42_love_dynamics_network.md)を基準に，問い，観測規則，モデル，検証方法を順に具体化する．式の複雑さではなく，定義した問いへ再現可能な計算で答えられることを目指す．すべての拡張を実装する必要はない．
:::

:::{warning} 対象の制限
実在人物の感情を推定・評価しない．公開された創作作品または仮想データを対象とする．作品内の台詞や行動に付けた評価値と，登場人物の内面そのものを区別する．
:::

## 卒業研究としての問いを絞る

基準Notebookの係数を変えて図を描くだけでは，研究の問いへの回答にならない．何を固定し，何を変え，どの数値で比較し，結果の信頼性をどう確かめるかを加える．Strogatzで学んだ線形系の知識に，観測と推定の設計を組み合わせれば，低次元の線形モデルも卒業研究の対象になる．

次のいずれか1つから始める．

| 研究の方向 | 問いの例 | 最初に用意するもの |
| --- | --- | --- |
| 数理・計算 | 安定性が同じネットワークで，一時的増幅はどう異なるか | 構造と重みの比較条件，厳密解での検証 |
| 推定方法の検証 | 観測間隔や初期値によって，係数をどこまで復元できるか | 真の係数が既知の仮想データ，誤差指標 |
| 作品の限定的な記述 | 定義した評価尺度の変化を，単純なモデルがどこまで説明するか | 場面範囲，評価基準，未使用場面 |

作品データを使わない場合でも，理論予測，数値検証，条件を変えた比較，限界の考察まであれば研究としてまとめられる．仮想データで推定が成功しても，実際の作品の関係変化を説明できたことにはならない．研究対象ごとに結論の範囲を明記する．

![作品の観測から基準モデル，拡張，未使用データでの検証へ進む流れ．](../assets/figures/concepts/relation_research_pipeline.png)

この図では資料から観測表を作り，モデルの比較へ進む．拡張の検討は，基準モデルのどこが不十分だったかを確認した後に行う．拡張が改善しなかった結果や，係数を識別できなかった結果も，検証方法が適切なら結論となる．

## 対象と時間を定義する

作品名，版，人物，場面範囲，除外基準を記録する．仮想データなら生成式，係数，初期値，乱数seedを記録する．別の人が同じ入力を作れることが最初の到達点である．

時間の扱いには少なくとも次の選択がある．

- 作中の経過時間が分かる場合は，実際の観測時刻 $t_k$ を使う．観測間隔は等しくなくてもよい．
- 場面順しか分からない場合は，場面番号 $k$ を時間の代用にするという仮定を明記する．係数を実時間あたりの反応速度とは解釈しない．
- 話ごとの変化そのものを扱うなら，離散時間モデル $\mathbf{x}_{k+1}=F\mathbf{x}_k$ を基準にしてもよい．

連続時間の係数行列 $M$ と，離散時間の遷移行列 $F$ は別物である．等間隔 $\Delta t$ で線形ODEを観測した場合には

```{math}
F=e^{M\Delta t}
```

が正確な対応になる．$F=I+\Delta t M$ は前進Euler法の近似にすぎない．連続時間の漸近安定条件は固有値の実部が負，離散時間では固有値の絶対値が1未満である．小さな $\Delta t$ の近似を，1話などの大きさが不明な間隔へそのまま適用しない．

また，$F$ から $M$ を一意に復元できるとは限らない．周期運動では1サンプル間に何周したかを区別できない場合がある．まず連続時間の反応速度を推定したいのか，観測時刻間の遷移を記述したいのかを決める．

## 状態と観測値を分ける

好意や敵意という語だけでは数値を定義できない．どの台詞，行動，語りを根拠とし，どの値を付けるかを文章化する．このように観察手順で意味を定めることを{abbr}`操作的定義(観察や測定の具体的手順によって概念の意味を定めること)`という．

記録には場面ID，時刻，評価対象，評価値，評価者，根拠，観測の有無を含める．中立を0とした場合でも，登場しなかった場面や判断できなかった場面を0にしない．{abbr}`欠測(観測値が得られていないこと)`は `NaN` と別の観測フラグで管理する．

### 順序尺度を連続値として使うための仮定

$-2,-1,0,1,2$ の5段階評価が強弱の順だけを表すなら，それは{abbr}`順序尺度(値の順序に意味があるが，隣り合う段階の差が等しいとは限らない尺度)`である．$1$ から $2$ への変化と $0$ から $1$ への変化が同じ大きさだとは，順位だけからは言えない．ODEの状態値へそのまま代入したり，二乗誤差を計算したりするには，段階間の間隔にも意味を与える追加仮定が必要になる．

最初の研究では，等間隔の数値化を便宜的に採用すると明示し，別の順序を保つ数値化でも結論が変わらないかを調べる方法がある．たとえば $(-2,-1,0,1,2)$ と $(-2,-0.5,0,0.5,2)$ では順序は同じだが距離は異なる．各尺度内で基準・拡張を比較し，異なる尺度の二乗誤差をそのまま大小比較しない．

別の方法は，連続状態から閾値で観測カテゴリを作る{abbr}`観測モデル(モデル内部の状態と実際に記録する値の対応を定める式)`を置くことである．この場合はカテゴリの予測を評価する．閾値や観測誤差まで同時に推定すると自由度が増えるため，最初からすべてを未知にしない．

### 連続値の観測モデル

間隔に意味のある連続指標を使う場合の最小表現は

```{math}
:label: eq-relation-observation
\mathbf{y}_k=H\mathbf{x}(t_k)+\boldsymbol{\varepsilon}_k
```

である．$\mathbf{x}$ はODEの状態，$\mathbf{y}_k$ は記録した観測値，$H$ は観測する成分を選ぶ行列，$\boldsymbol{\varepsilon}_k$ は観測とモデルの対応のずれである．全成分を同じ尺度で観測すると仮定するなら $H=I$ と置く．状態を観測値と同一視したかどうかを，この式で明示する．誤差の独立性や正規分布は自動的に成り立つものではない．

## 少量の評価で観測規則を試す

少数場面を複数人が独立に評価するか，時間を空けて自分で再評価する．一致した割合だけでなく，どのカテゴリ同士で判断が分かれたかの表と，場面ごとの根拠を残す．同じ中立カテゴリが多いだけで一致率が高くなることもある．

不一致を見て基準を修正したら，修正に使わなかった場面でも確認する．再現性が低い状態で複雑なモデルへ進むと，観測規則の揺れを新しい相互作用として説明してしまう可能性がある．評価基準の版，変更理由，再評価した範囲を保存する．

## 単純な基準モデルを検証する

初めに，直前値をそのまま予測する持続モデル，自己減衰だけの対角行列モデル，相互作用を含む2変数モデルを候補にする．研究の問いに合う基準を選び，同じ予測条件で比較する．相互作用を含むモデルは

```{math}
\dot{\mathbf{x}}=M\mathbf{x},\qquad
M=\begin{pmatrix}a&b\\c&d\end{pmatrix}
```

である．自由係数は4個だが，対称性や共通減衰を仮定すれば減らせる．仮定は学習誤差を下げるために後から変更するのではなく，モデル表に記録して比較する．

作品へ適合させる前に，既知の行列と初期値から生成した仮想データで，41章の厳密解と数値解を照合する．その後に観測誤差や欠測を加える．誤差のない仮想データでも復元できないなら，作品解釈より前に添字，時間単位，推定方法，識別可能性を確認する．

{abbr}`残差(観測値からモデルの予測値を引いた差)`は $r_{k\ell}=y_{k\ell}-\hat y_{k\ell}$ とし，時刻順に描く．同じ符号が続く，出来事の後だけ大きくなる，振幅を過大評価するといった構造を記録する．ただし，残差は拡張の候補を考える材料であり，第三者効果の存在や因果関係の証明ではない．時間の定義，尺度，欠測処理，観測誤差でも同様の構造が生じる．

## 係数を観測時刻の解に適合させる

未知係数を $\boldsymbol{\theta}$ にまとめ，推定に使う観測成分の集合を $\mathcal O_{\mathrm{train}}$ とする．連続指標を使う場合には，たとえば

```{math}
:label: eq-relation-fitting-loss
L(\boldsymbol{\theta})=
\frac{1}{N_{\mathrm{train}}}
\sum_{(k,\ell)\in\mathcal O_{\mathrm{train}}}
\left[\frac{y_{k\ell}-\{H\mathbf{x}_{\boldsymbol{\theta}}(t_k)\}_{\ell}}{s_\ell}\right]^2,
\qquad N_{\mathrm{train}}=|\mathcal O_{\mathrm{train}}|
```

を最小化する．$s_\ell>0$ は成分の尺度をそろえるための定数で，同じ単位なら1でもよい．学習区間のデータから決めるか，事前に固定し，検証区間の結果に合わせて変更しない．欠測は和から除外し，その数を分母へ含めない．初期状態も未知なら，追加の推定対象として数える．

実装は，係数候補から行列を作る，観測時刻でODEを解く，観測成分を選ぶ，残差を1次元配列へ並べる，という順になる．以下は $H=I$，初期状態既知の場合の中心部分である．

```python
import numpy as np
from scipy.linalg import expm
from scipy.optimize import least_squares

def residuals(theta):
    M = matrix_from_parameters(theta)  # 採用した少数係数の構造を実装する．
    prediction = np.array([expm(M * (t - t0)) @ x0 for t in t_train])
    scaled = (y_train - prediction) / scale
    return scaled[observed_train]  # 同じ形のbool配列で欠測を除く．

fit = least_squares(residuals, theta0, bounds=(lower, upper))
```

必要な変数は，学習時刻 `t_train`，観測値 `y_train`，観測フラグ `observed_train`，成分ごとの正の尺度 `scale`，初期時刻と状態，係数の初期候補と範囲である．範囲を設ける理由も記録する．`least_squares` は残差ベクトルから局所的な最小二乗解を探すため，終了したことだけでは大域的最適性も識別可能性も保証しない．複数の初期候補と残差を確認する．[SciPyのleast_squares文書](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)

観測値を差分して $\dot{\mathbf{x}}\approx(\mathbf{y}_{k+1}-\mathbf{y}_k)/\Delta t$ と置く推定は簡便だが，観測誤差を増幅する．独立で分散 $\sigma^2$ の誤差を差分すると，その分散は $2\sigma^2/\Delta t^2$ になる．まず観測値そのものへ解を適合させる方法を基準とし，差分を使う場合は誤差と刻みへの感度を調べる．

## 推定できる係数の範囲を確かめる

異なる係数が同じ観測を生む場合を{abbr}`識別不能(異なるパラメータ値を観測から区別できないこと)`という．観測点数が係数数より多いだけでは，識別可能とは限らない．

たとえば2変数系で観測した状態がすべて $\mathbf{x}(t)=q(t)\mathbf{v}$ という1方向上にあると，データが教えるのは $M\mathbf{v}$ だけである．$N\mathbf{v}=0$ を満たす行列 $N$ を加えても，その軌道上では $(M+N)\mathbf{x}=M\mathbf{x}$ となる．この実験だけから4係数すべてを一意には決められない．

```{dropdown} 行列の階数から考える識別可能性
状態と時間微分を正確に観測できた理想条件を考える．各時刻の状態を列に並べた行列を $X$，微分を並べた行列を $\dot X$ とすると $\dot X=MX$ である．状態数を $p$ として $\operatorname{rank}X=p$ なら，$XX^\top$ が可逆なので $M=\dot X X^\top(XX^\top)^{-1}$ と復元できる．階数が足りなければ，観測していない方向の作用は決まらない．

階数が形式上足りても，列がほぼ同じ方向なら観測誤差に敏感になる．特異値や条件数を調べ，異なる方向を励起する初期値を仮想実験で比較するとよい．これは理想条件での説明であり，実データの微分を正確に観測できるという意味ではない．数値実装では逆行列を明示的に作るより，最小二乗計算を使う．
```

42章の $M=-\alpha I+\beta A$ で $A$ と $\beta$ を両方自由に推定すると，任意の $c>0$ に対して $(\beta,A)$ と $(\beta/c,cA)$ は同じ $M$ を与える．$A$ の尺度を固定するか，$\beta A$ をまとめて推定しなければ，両者を分けて解釈できない．

複数の推定初期値，学習区間，観測誤差の大きさを変えて，係数と予測がどれほど変わるかを調べる．{abbr}`正則化(係数の大きさや複雑さに追加の制約を与える推定方法)`は推定を安定化する場合があるが，データにない識別情報を新しく生むわけではない．係数が不安定でも予測が安定な場合は，係数の意味の説明を控え，予測可能な範囲を結論にする．

## 拡張する状態と係数を区別する

3人のモデルには異なる設計がある．

| 設計 | 時間変化する状態 | 線形係数行列の大きさ |
| --- | --- | --- |
| 人物ごとに1変数 | $\mathbf{x}=(x_1,x_2,x_3)^\top$ | $3\times3$ |
| 各人物から他の人物への有向状態 | $\mathbf{z}=(z_{12},z_{13},z_{21},z_{23},z_{31},z_{32})^\top$ | $6\times6$ |

ここでは $z_{ij}$ を人物 $i$ が人物 $j$ に向ける状態と定義する．42章の $A_{ij}$ が $j$ から $i$ への固定係数だったことと混同しないよう，記号を分けた．有向状態は3人なら $3(3-1)=6$ 個で，その時間発展を $\dot{\mathbf{z}}=C\mathbf{z}$ とすると無制約の $C$ には36係数がある．3行3列に状態を並べて表示できても，その表示用行列がそのまま時間発展の係数行列になるわけではない．

最初は必要な状態だけを選び，共通係数やゼロ固定で未知数を減らす．第三者効果を追加する場合も，どの状態の変化率に，どの観測可能な量が入るのかを書いてから1項だけ試す．積を用いる非線形項は，入力の片方が負になると符号が変わる．正の係数を付ければ常に嫉妬を表す，とは言えない．追加項が0のとき基準モデルへ戻ることも検証する．

## 外力と状態の跳びを分ける

出来事を入力 $\mathbf{u}(t)$ として表すなら，

```{math}
\dot{\mathbf{x}}=M\mathbf{x}+B\mathbf{u}(t),\qquad
\mathbf{x}(t)=e^{M(t-t_0)}\mathbf{x}(t_0)
+\int_{t_0}^{t}e^{M(t-s)}B\mathbf{u}(s)\,ds
```

となる．$B$ は出来事が各状態の変化率へ与える影響を定める．一定の持続時間を持つ入力は，その区間中の変化率を変え，通常は状態を連続的に変化させる．瞬時に状態を変える仮定なら，出来事の直前・直後を $t_e^-,t_e^+$ として $\mathbf{x}(t_e^+)=\mathbf{x}(t_e^-)+\mathbf{b}$ と別に定義する．時間刻みごとに同じ値を加算して，刻みを変えると総効果が変わる実装にしない．

入力が不連続になる時刻では，その前後で積分区間を分けると検証しやすい．作品の各場面に自由な外力を置けばどの変化にも適合できてしまうので，入力の種類，時刻，持続時間，推定係数の数を限定する．

## 非線形飽和を追加する場合の確認

線形モデルの無限の発散が指標の意味に反するなら，飽和を検討する．ただし，右辺に `tanh` を入れるだけで状態の上限が保証されるわけではない．たとえば $\dot x=\tanh x$ は，$x(0)>0$ なら無限に増加する．

減衰を残した $\dot{\mathbf{x}}=-\alpha\mathbf{x}+\beta A\tanh(\mathbf{x}/s)+\mathbf{u}(t)$ で，$\alpha>0,s>0$，入力が $|u_i(t)|\le U_i$ と有界なら，$|\tanh|\le1$ より

```{math}
|x_i(t)|\le e^{-\alpha t}|x_i(0)|
+\frac{\beta\sum_j|A_{ij}|+U_i}{\alpha}(1-e^{-\alpha t})
\quad(t\ge0,\ \beta\ge0)
```

と評価できる．これは有界性の保証であり，評価尺度の区間 $[-2,2]$ を自動的に保つ保証ではない．その区間が必要なら境界で外向きに動かない条件も確認する．$s$ は状態の尺度であり，数式と単位をそろえる．飽和の形や尺度を選ぶこと自体を研究上の仮定として記録する．

## 学習と未使用データでの検証を分ける

前半で推定し，別の区間で候補や正則化の強さを選び，最後の区間で最終評価する．データが少ない場合は，時点を前へ進めながら過去だけで推定する検証方法もある．隣接場面を無作為に混ぜると未来の情報を使いやすいため，時間順序を保つ．尺度変換，欠測補間，モデル選択も学習側だけで決める．

評価する予測には次の違いがある．

- 1時点先予測は，各予測時点で利用可能な直前までの観測を使う．持続モデルも同じ観測を使える条件にする．
- 連続した将来区間の予測は，分割点の状態から先を観測値でリセットせず計算する．持続モデルは分割点の値を保つ．

この2つの誤差を同じ意味として比較しない．後半の出来事を既知の外力として与えるなら，その入力が予測時点で利用できるのかを確認する．事後的に分かった出来事を与えた計算は，出来事を条件とした再現であり，未知の未来の予測とは区別して報告する．

連続指標なら，未使用の観測成分だけでRMSEを計算できる．

```{math}
\operatorname{RMSE}_{\mathrm{test}}
=\sqrt{\frac{1}{N_{\mathrm{test}}}
\sum_{(k,\ell)\in\mathcal O_{\mathrm{test}}}
(y_{k\ell}-\hat y_{k\ell})^2}
```

異なる単位の成分は成分別に報告するか，学習時に固定した尺度で標準化する．順序カテゴリには，観測モデルに合わせた一致率やカテゴリ別の誤りも使い，数値の距離を使う指標には仮定を付記する．同じデータ分割，同じ観測点，同じ予測条件で基準と拡張を比較する．

仮想データで誤差を加える研究なら複数seedで繰り返し，係数誤差と予測誤差の分布を分けて示す．1本の作品時系列の隣接場面を独立な反復実験と数えない．拡張モデルの学習誤差が小さくても，未使用データで改善するとは限らない．

## 到達点と発展の選び方

最小の到達点は，1つの問い，検証済みの基準モデル，同じ条件での比較，誤差または感度の評価，限界を示すことである．新しい項を追加して改善することを必須条件にしない．

| 段階 | 残す成果 |
| --- | --- |
| 基礎の確認 | 添字規約，固有値，厳密解との誤差，境界例の検証 |
| 卒研の中心 | 1つの問い，比較条件，複数条件の結果，解釈と限界 |
| 推定を含む場合 | 観測モデル，少数係数，識別可能性，学習・未使用区間の比較 |
| 余力がある場合 | 第三者，外力，飽和のいずれか1つの追加と同じ条件での再評価 |

場面数や評価の再現性が不足するなら，人物数や係数を減らすか，仮想データで観測・推定方法を検証する研究へ限定する．その変更理由も成果の一部として記録する．
