# 卒研ロードマップ：生成模様と実画像を比較する

## この章の目的

[反応拡散モデル](./21_reaction_diffusion_basic.md)と[画像特徴量](./22_reaction_diffusion_snake.md)を使い，自分で定めた問いに答える研究を組み立てる．目標は似た模様を1枚見つけることではなく，**選んだモデルが，指定した観測条件で，模様のどの性質をどこまで再現できるか**を根拠付きで述べることである．

画像の収集から比較までを再実行可能にし，数値計算の誤差，画像処理への依存，個体差，初期条件によるばらつきを区別する．実画像との一致が得られなくても，探索した範囲と比較方法の下で何が一致しなかったかを示せれば，検証可能な研究成果になる．

## 卒業研究としての到達点を定める

最初から複雑なモデルや多数の特徴量を導入する必要はない．まず1つの特徴量で処理を通し，その限界を確認してから，別の性質を測る量を追加する．標準的な到達点は次のとおりである．

| 段階 | 自分で判断・実装する内容 | 残す成果 |
| --- | --- | --- |
| 基礎検証 | 既知解，格子・時間刻み，人工画像の検証 | 誤差表と検証コード |
| 問いと観測 | 対象範囲，独立な標本，長さの対応 | 画像一覧と比較条件 |
| 測定 | 前処理と2つ程度の補完的な特徴量 | 処理画像と特徴量表 |
| 探索 | 比較指標，パラメータ範囲，複数seed | 特徴量地図と候補群 |
| 検証 | 未使用画像，別seed，前処理への感度 | 検証誤差とばらつきの図 |
| 考察 | 一致する性質，一致しない性質，非一意性 | 根拠を限定した結論 |

既存Notebookを実行して画像を並べるだけでは，この研究上の判断が不足する．一方，生成機構の生物学的な証明や高度な推定手法の導入までは必要ない．1特徴量だけを扱う場合も，その測定精度・頑健性・パラメータを区別できる範囲を独立した問いにすれば方法論の研究になる．

## 研究の問いと対象を絞る

対象種，部位，模様タイプを限定する．たとえば，同一種の体側画像について，前景面積比と代表的な間隔をGray--Scottの同じパラメータ候補群で説明できるか，という問いを置ける．面積と間隔の両方を選ぶのは，同じ面積比でも斑点の大きさや配置が異なりうるからである．

最初に，対象種・部位，個体数，画像数，測定したい性質，画像の出典・利用条件を記録する．測定の単位が個体なのか，1枚の写真なのかも決める．同じ個体の10枚を10個体として数えたり，同じ写真から切り出した10領域を独立標本とみなしたりすると，情報量を過大評価する．

標本数が少ない場合は，対象画像群に限ったケーススタディであると明示する．標本数が多いように見せるために同じ画像を細分化するのではなく，画像内・個体内・個体間の変動を区別する．

## データを推定用と検証用に分ける

**{abbr}`推定用データ(処理条件やモデルパラメータを選ぶためのデータ)`**と，選択には使わない**{abbr}`検証用データ(選んだ手順を未使用の対象で評価するためのデータ)`**を分ける．同じ個体や同じ元写真に由来する画像は同じ側へまとめる．切り出し画像だけを無作為に分けると，ほぼ同じ情報が両方に入り，独立した検証にならない場合がある．

画像数が十分なら分割を保存して比較する．少ない場合は1個体ずつ除外する検証なども考えられるが，各回の前処理・重み・パラメータ選択は残りの個体だけで行う．独立な検証ができない場合はその限界を明記し，人工画像による検証や条件を変えた感度分析で補う．

同じ画像への一致だけを報告することは，それだけで過適合を証明するわけではない．しかし，未使用データでも成り立つという根拠にはならず，過適合を検出しにくい．検証結果を見て方法を変更した場合，そのデータは以後の選択に使ったデータであると記録する．

## 観測手順と長さの対応を固定する

![実画像と生成模様に観測・測定手順を適用して比較する流れ．](../assets/figures/concepts/pattern_research_pipeline.png)

図では実画像と生成画像から同じ特徴量へ進むが，その前に大きさ，前景，切り出し方をそろえる必要がある．元画像を上書きせず，原本，関心領域，前処理画像，二値画像，特徴量表を同じ識別子で結び付ける．

### 写真の画素とモデルの長さを対応させる

同じ192×192画素へ変更しても，同じ大きさの体表を観測しているとは限らない．物差しなどの較正情報があれば，1画素当たりの実長を用いる．ない場合は，体幅など比較可能な基準長で波長を割った無次元量を使い，その基準の測り方と誤差を記録する．いずれも得られなければ，絶対的な模様間隔の比較には限界がある．

Gray--Scottの長さは無次元である．モデルの1長さを実長 $s$ に対応させるなら，$\ell_{\rm photo}=s\ell_{\rm model}$ となる．$s$ を固定する根拠を示すか，推定する未知量として $\theta=(F,k,s)$ に含める．生成画像ごとに自由に拡大縮小してから波長の一致を評価すると，その一致は拡大縮小によって作られてしまう．$s$ を追加するほど他のパラメータを区別しにくくなる点にも注意する．

### 前処理を再現できるようにする

1. 同じ部位の**{abbr}`関心領域(画像のうち解析対象として選択する範囲)`**を切り出し，座標を保存する．
2. 向きと長さの基準をそろえ，補間方法と解像度を記録する．
3. 背景，強い影，損傷した部分を扱う規則を決める．
4. グレースケール化，前景の明暗，平滑化，二値化を定義する．
5. 処理前後を並べて保存し，模様を消したり背景を加えたりしていないか確認する．

固定閾値，自動閾値，手動閾値のどれも選択規則と値を残す．手動でも座標や閾値を保存すれば同じ処理は再実行できるが，選ぶ人による差を検証する必要がある．自動法でも設定の選択による依存性は残る．推定用画像で決めた手順を，検証用画像へ同じ規則で適用する．

不規則な関心領域の外を0にしてFFTへ入力すると，領域の形や端の段差もスペクトルに含まれる．最初は共通条件の長方形領域を使い，窓関数の有無と切り出しへの感度を確認する方が検証しやすい．

### 濃度場から比較用画像を作る

モデル濃度 $v$ は写真の輝度そのものではない．**{abbr}`観測写像(モデルの状態から実際に比較する観測量へ変換する規則)`** $H$ を定義し，$I_{\rm sim}=H(v)$ を比較用画像とする．たとえば濃度の高い領域を写真の暗い前景に対応させるなら，写真側の明暗を反転するなどして前景の定義を統一する．

$H$ には画素間隔への再標本化，切り出し，必要なら平滑化や濃度の二値化も含める．値の範囲が違う写真と濃度場に同じ数値の閾値を使うだけでは，同じ測定にはならない．反対に，各画像の最小値と最大値で常に0から1へ引き伸ばすと，ほぼ一様な場の微小差まで鮮明な模様になる．無模様と低コントラストを判定する基準は引き伸ばす前の量で決める．

周期モデルの全領域を周期成分数で測り，写真だけを開いた境界で測る比較は避ける．たとえば生成場から写真と同じ面積の領域を切り出し，両方に同じ開いた境界の測定を適用する．モデルの境界条件と，画像を測るときの境界規約は別の設定である．

## 特徴量を選び，観測側の変動を測る

最初は面積比などの1量を選び，22章の人工画像で検証する．次に連結成分の面積分布や特徴波長などを加え，互いの不足を補えるか確認する．波長と平均斑点径のように強く関連する特徴量を増やすだけでは，情報があまり増えない場合もある．

個体ごとの値を点で示し，平均だけでなく範囲や標準偏差を併記する．同じ個体の複数領域を測る場合は，個体内で集約するか階層を保って表示する．標準偏差は観測値のばらつきであり，平均値の推定精度と同じではない．画素数を独立標本数とみなして平均値の誤差を小さく見積もらない．

次に，切り出し位置，閾値，平滑化幅をあらかじめ定めた範囲で変える．その変化が個体差と同程度なら，モデルとの小さな差を生物学的な差として論じることは難しい．画像ごとの点と処理条件による変化を同じ図に描くと，どの不確かさが支配的か分かる．

## 反応拡散計算を検証して基準条件を作る

21章の既知解と非負性の検証を通してから探索する．Gray--Scottの基準平衡点 $(1,0)$ は線形安定なので，本Notebookは有限振幅の初期条件からの発展を調べていると明記する．模様を生成できたことをチューリング不安定性の確認と呼ばない．

| 固定・記録する項目 | 必要な理由 |
| --- | --- |
| $D_u,D_v,L,N,\Delta x=L/N$ | 拡散の長さと領域・解像度を区別する |
| $\Delta t,t_{\rm end}$，保存時刻 | 時間離散誤差と観測時刻を区別する |
| 境界条件と連続的な初期分布 | 比較のモデル条件をそろえる |
| seedの集合と変動の振幅 | 初期条件によるばらつきを再現する |
| 数値異常の検出条件 | 発散を模様として測定しない |
| 観測写像 $H$ と測定条件 | 写真と生成場を同じ基準で比べる |

格子検証では $L$ と $t_{\rm end}$ を固定し，同じ初期分布を異なる格子で標本化する．$N$ を増やして $\Delta x$ を減らし，拡散の条件に応じて $\Delta t$ も減らす．長時間の模様が点ごとに一致しない場合でも，まず短時間の既知解・場の誤差を確認し，次に特徴量とそのseed間変動に対する刻み依存性を報告する．

終了条件は，固定時刻の模様を比べるのか，定常性を確かめた状態を比べるのか選ぶ．固定時刻の比較も明確な研究対象になるが，定常パターンとは呼ばない．複数時刻を保存し，まだ模様が広がっている最中でないか確認する．

最初に1条件を複数seedで計算し，初期変動への感度を測る．探索中は共通のseed集合を各パラメータに使うと，乱数の違いに由来する比較のばらつきを抑えやすい．候補決定後には未使用seedでも検証する．よく似た1回だけを選ばず，試したseed全体を残す．

## 1特徴量で探索を動かす

パラメータを $\theta=(F,k)$ とし，最初は $D_u,D_v,L$ などを固定する．正の範囲を粗い格子で調べ，計算失敗，一様な状態，模様が残った状態を区別して記録する．初期値，終了時刻，格子によって結果が変わるため，地図は指定した条件の結果である．

独立な観測単位を $a=1,\ldots,M$，生成のseedを $r=1,\ldots,R$ とする．特徴量 $\phi_j$ の平均を

```{math}
\bar\phi_{\mathrm{obs},j}=\frac1M\sum_{a=1}^M\phi_j(I_a),\qquad
\bar\phi_{\mathrm{sim},j}(\theta)=\frac1R\sum_{r=1}^R\phi_j(H(v_{\theta,r}))
```

と定める．同じ個体の複数画像がある場合は，たとえば個体内で平均した値を1つの $\phi_j(I_a)$ として，各個体を等しく重み付けする．最初の損失は

```{math}
L_1(\theta)=|\bar\phi_{\mathrm{sim},1}(\theta)-\bar\phi_{\mathrm{obs},1}|
```

とする．損失は小さいほど，選んだ特徴量の平均が近い．画像全体の類似性や分布の一致まで意味するものではない．

すべての格子点の値を表へ保存してから特徴量地図を描く．都合のよい画像だけを保存すると，どの範囲で合うのか分からなくなる．粗探索で変化の大きい領域や良好な候補の周辺を見つけ，その根拠を記録してから細かく調べる．

## 補完的な特徴量を組み合わせる

単位の異なる特徴量をそのまま足さず，尺度 $s_j>0$ で割って無次元化する．一例は

```{math}
L(\theta)=\sum_{j=1}^{p}w_j
\left[\frac{\bar\phi_{\mathrm{sim},j}(\theta)-\bar\phi_{\mathrm{obs},j}}{s_j}\right]^2,
\qquad w_j\ge0,\quad\sum_jw_j=1
```

である．$s_j$ には推定用データの標準偏差や，研究上区別したい差の大きさを用いる．標準偏差が0や極端に小さい場合は割れない，または不当に大きな重みになるので，事前に意味のある正の下限を定めるか，その特徴量を採用しない．検証用データで尺度を調整してはいけない．

たとえば面積比の差0.02と波長の差2 mmを比べる場合，それぞれの尺度が0.05と5 mmなら規格化した差はどちらも0.4である．$w_1=w_2=0.5$ なら損失は0.16になる．尺度と重みは異なる役割を持ち，両方を記録する．重みを少し変えただけで候補が入れ替わるなら，順位にはその依存性がある．

この損失は平均の差を測る．生成結果の平均が一致しても，seedごとの値が大きくばらつく場合がある．平均に加え，個々の点と分布を比較する．各seedの二乗誤差を先に計算して平均する方法は，平均の差に加えて生成側の分散も罰する別の損失であり，同じ式ではない．どちらを使うかを問いに合わせて選ぶ．

### 未定義の特徴量と計算失敗を扱う

一定画像には代表波長を割り当てられない．この `NaN` を0へ置き換えたり，無視して残ったseedだけの平均を取ったりすると比較が変質する．数値計算の失敗と，正常に計算された一様状態も区別する．

たとえば周期模様を比較する研究なら，事前に決めたコントラスト・周期性の基準を満たす割合を別の量として報告する．すべてのseedで波長が定義できる候補だけを波長損失で比較する，または未定義の結果に別の罰則を設けるなど，扱いを明記する．どの規則でも除外数と全試行数を残し，合うseedだけで結論を作らない．

## 適合候補を未使用データで検証する

推定用画像で選んだ $\theta$，尺度，重み，観測写像を固定して，検証用画像と未使用seedへ適用する．推定時と検証時の誤差を並べ，前処理への感度も示す．一度にすべてを変えると原因が分からないので，まず閾値だけ，次に格子だけというように比較条件を整理する．

最良の1点に加え，損失が近い候補の画像と特徴量も残す．2つのパラメータから1つの特徴量だけを測ると，異なる組合せが同じ値を生むことが多い．特徴量を増やしても，写像 $\theta\mapsto(\phi_1,\ldots,\phi_p)$ が一対一になる保証はない．この**{abbr}`識別可能性(異なるパラメータを観測量から区別できる性質)`**の問題を確認するため，損失地図や特徴量空間で候補の重なりを示す．

同程度の候補をまとめる損失の許容幅を用いる場合，その幅を選んだ根拠を記す．単に損失が小さい領域を描いただけでは統計的な信頼区間にはならない．画像特徴に合った $F,k$ はモデル内の適合パラメータであり，生物体内の反応速度を測定した値とは限らない．

## 結果をどこまで主張できるか整理する

| 結果 | 主張できる範囲 | 追加の根拠なしには主張できないこと |
| --- | --- | --- |
| 特徴量が近い | 指定した測定量で類似する | 画像の全性質が一致する |
| 検証画像でも近い | その検証対象にも比較手順が適用できた | すべての種・個体へ一般化する |
| 複数の候補が近い | 今の観測量では候補を区別しにくい | 真のパラメータを一意に推定した |
| 探索範囲に良好な候補がない | 試した条件・尺度・特徴量では十分に合わない | モデルの全パラメータで再現不可能である |
| 模様を生成できた | 数理モデルがその模様を生みうる | 実際のヘビが同じ機構で模様を作る |

成長，曲面，鱗の構造，遺伝・発生過程を本モデルは直接扱わない．制約を列挙するだけでなく，たとえば曲面による長さのゆがみが波長比較へ影響しうる，というように自分の測定結果へ結び付けて考察する．

## 対象や計算量を絞る場合

| 制約 | 研究の問いを保つ調整 |
| --- | --- |
| 実画像の利用条件が整わない | 既知の周期・面積・ノイズを持つ人工画像で比較法を評価する |
| 独立個体が少ない | 対象画像に限った事例研究とし，前処理の感度を重点的に測る |
| 探索が重い | 自由パラメータと探索点を減らし，有望領域を追加検証する |
| 候補が区別できない | 非一意性を可視化し，追加すると有効な特徴量を検討する |
| 特徴量が不安定 | 模様への適合から，測定法の精度と頑健性の比較へ問いを絞る |

計算量を減らすために格子を粗くする場合も，基準計算との誤差を確認する．人工的な観測データを別seedや別条件で作る研究では，設定した真値を使って答えに合わせるのではなく，探索用と評価用のデータを分けて手順を評価する．同じモデルでデータを生成しても真のパラメータが一意に戻るとは限らず，実際の生物機構の妥当性を検証したことにもならない．

## 研究記録のテンプレート

```text
研究の問いと対象範囲：
画像の出典・利用条件・独立な観測単位：
推定用と検証用の分割：
関心領域・長さの基準・前景の定義：
前処理と観測写像 H：
特徴量の式・単位・人工画像での検証：
反応拡散の領域・初期条件・刻み・終了時刻：
既知解・刻み変更での検証：
探索範囲・seed集合・追加探索の根拠：
損失の尺度・重み・未定義値の扱い：
検証用画像・未使用seedでの結果：
結論を支える図と，主張できないこと：
```

## チェックポイント

- [ ] 問いに答えるために必要な特徴量と比較対象を説明できる．
- [ ] 同じ個体や元写真からの画像を独立標本として数えていない．
- [ ] 画素数と実長を区別し，写真とモデルの観測条件をそろえた．
- [ ] 数値誤差，初期条件のばらつき，前処理の感度を別々に示した．
- [ ] 損失の単位をそろえ，未定義値と計算失敗の扱いを記録した．
- [ ] 未使用の対象で検証し，同程度に適合する候補も調べた．
- [ ] 適合の成否にかかわらず，問いに対する根拠付きの結論を書ける．
