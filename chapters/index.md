# 卒業研究準備セミナー：数理モデリングとシミュレーション

本教材は、Strogatz『Nonlinear Dynamics and Chaos』を輪講し、常微分方程式・線形安定性・固有値・相図の基礎を学んだ情報数理学科4年生を対象とする。**偏微分方程式は未履修であることを前提**とし、偏微分、初期条件・境界条件、拡散方程式、有限差分法から始める。

目標は、PDEの公式を覚えることではない。既習の力学系を空間へ拡張し、各自の卒業研究について「何を状態とし、何を比較し、何を図にし、どう検証するか」を説明できるようになることである。

## 学び方

輪講前に、全員が次の2つを読む。

1. [研究設計と数理モデリングの作法](./00_research_design.md)
2. [ODEからPDEへ：拡散方程式入門](./00_pde_foundations.md)

2つ目には対応Notebookがある。1次元拡散方程式を実行し、安定条件を満たす計算と、破って発散する計算の両方を確認しておく。

## 輪講の順序

4人の学生が**1人1回、50分**を担当する。各回は前半の基礎章と後半の研究接続章を1つのテーマとして扱う。

| 回 | 教材 | 学ぶ中心 | 次の回への橋渡し |
| --- | --- | --- | --- |
| 第1回 | [放熱 I](./01_stegosaurus_heat_basic.md)・[放熱 II](./02_stegosaurus_heat_shape.md) | 拡散、境界条件、定常化、形状比較 | 拡散項を第2回で再利用する |
| 第2回 | [反応拡散 I](./03_reaction_diffusion_basic.md)・[反応拡散 II](./04_reaction_diffusion_snake.md) | 拡散＋反応、空間パターン、特徴量 | 局所更新という見方を第3回へ渡す |
| 第3回 | [乗降 I](./05_agent_boarding_basic.md)・[乗降 II](./06_agent_boarding_behavior.md) | 離散空間、個体、行動規則 | 多数の要素の結合を第4回へ渡す |
| 第4回 | [恋愛 I](./07_love_dynamics_basic.md)・[恋愛 II](./08_love_dynamics_network.md) | 既習ODE、外力、高次元化、ネットワーク | 4種類のモデルを統合する |

この順序により、PDEを初めて学ぶ学生も、拡散という共通部品を2回続けて使える。その後、同じ「局所則から全体挙動が生まれる」という考えを、離散個体とネットワークへ広げる。

## 50分の共通構成

| 時間 | 内容 |
| ---: | --- |
| 0–5分 | 問いと前回との接続 |
| 5–15分 | 状態変数・仮定・最小モデル |
| 15–27分 | 方程式または更新規則 |
| 27–37分 | Notebookで1パラメータ比較 |
| 37–44分 | 評価指標・限界・卒研への接続 |
| 44–50分 | 質疑と知見の転用 |

各回の終了時、担当者以外も「この回から自分の研究へ移せる考え方」を1つ記録する。全4回の後、[4つのモデルを卒業研究へ移す](./09_synthesis.md)の転用シートを完成させる。

## この教材で身につけること

1. ODEとPDEの違いを、状態の持ち方から説明する。
2. PDEを方程式・初期条件・境界条件の組として読む。
3. 空間差分によってPDEを大きな連立ODEとして計算する。
4. 現象を状態変数・パラメータ・局所則へ翻訳する。
5. 見た目や動画を評価指標へ変換し、公平な比較実験を設計する。
6. 数値的不安定性、モデルの限界、現象についての主張を区別する。

:::{important} 科学的な扱いについて
本教材のモデルはいずれも教育用の簡略モデルである。ステゴサウルス背板の機能、動物模様の成因、鉄道運用、実在人物の関係などを断定するものではない。仮定と適用範囲を必ず確認すること。
