## この章の目的

第5章では、ドア付近に立つ人を **動かない障害物** として扱った。本章では、その人を **行動ルールを持つエージェント** に格上げする。固定型・横移動型・一時降車型などの行動を比較し、どの行動が停車時間を縮めるかを評価する。

## 現象の説明

混んだ電車では、ドア付近に立った人が、降りる人のために動くかどうかで流れが大きく変わる。「いったんホームに降りて道を空ける」人もいれば、「奥に詰めず立ち続ける」人もいる。これらは個々のエージェントの **行動ルール** の違いとして表現できる。

:::{warning} 科学的な注意
本章も **簡略モデル** であり、特定の乗客行動の良し悪しを断定するものではない。あくまで局所行動ルールが全体指標に与える影響を調べる教材である。
:::

## 最小モデル

第5章の CA を再利用し、ドア付近滞留者に **行動タイプ** を割り当てる。

| 行動タイプ | ルール |
| --- | --- |
| 固定型 | 動かない（第5章の障害物と同じ） |
| 横移動型 | 降車流の邪魔になるとき、横の空きセルへよける |
| 一時降車型 | 降車中は一度ホームへ出て、降車後に再乗車する |
| 協調型 | 周囲密度が高いと自発的に奥へ詰める |
| 非協調型 | 周囲が混んでも動かない |

## 数式による定式化

### 効用関数

各エージェントの行動選択を **効用関数** で表す。エージェント $i$ が行動 $a$ をとったときの効用を

```{math}
:label: eq-utility
U_i(a) = -\alpha\, d_i(a) - \beta\, \rho_i(a) - \gamma\, C_i(a) + \delta\, P_i(a)
```

とする。各項の意味は次のとおり。

- $d_i$：目的地（座席・降車口）までの距離。近いほど良い。
- $\rho_i$：移動先周囲の混雑度。空いている方が良い。
- $C_i$：移動コスト（動く労力、一時降車のコスト）。
- $P_i$：周囲を空けることで流れに与える正の効果（協調行動の報酬）。
- $\alpha,\beta,\gamma,\delta$：各要素の重み。エージェントの「性格」を決める。

### 行動選択

決定論的には効用最大の行動を選ぶ。

```{math}
:label: eq-argmax
a_i(t) = \arg\max_{a} U_i(a)
```

確率的には、効用に応じたソフトマックス選択をとる。

```{math}
:label: eq-softmax
P(a_i = a) = \frac{\exp\!\big(\lambda\,U_i(a)\big)}{\sum_{a'} \exp\!\big(\lambda\,U_i(a')\big)}
```

$\lambda$ は合理性の強さ（温度の逆数）である。$\lambda\to\infty$ で式 {eq}`eq-argmax` に一致し、$\lambda\to 0$ で完全ランダムになる。確率的選択は、人によるばらつきを表現するのに使う。

## パラメータの意味

| 記号 | 意味 |
| --- | --- |
| $\alpha,\beta,\gamma,\delta$ | 効用の重み（性格） |
| $\lambda$ | 行動の合理性（ばらつき） |
| 協調型の割合 | 集団の中で何割が協調的か |

行動タイプの **混合割合** がシナリオを決める。「全員固定型」と「半数が一時降車型」では、停車時間の分布が変わる。

## 数値シミュレーション

Notebook では次を行う（seed 固定、複数回試行）。

1. 第5章のモデルを関数として再利用する。
2. ドア付近滞留者に行動タイプを割り当てる。
3. 固定型・横移動型・一時降車型でそれぞれ複数回シミュレーションする。
4. 停車時間 $T_\mathrm{dwell}$ の **分布**（箱ひげ図またはヒストグラム）を描く。
5. ドア付近の **密度ヒートマップ** を行動タイプ別に比較する。

確率的要素を含むため、1回の結果ではなく **分布で比較** することが重要である。これは第00章で述べた「比較条件と評価指標」の実践でもある。

:::{note} 評価指標
評価指標は $T_\mathrm{dwell}$ の **平均と分散**、および密度ヒートマップである。単発の数値ではなく分布で語ること。
:::

## 卒業研究への接続

- 効用の重み $(\alpha,\beta,\gamma,\delta)$ を実測データに合わせて推定すれば、行動の「逆問題」になる。
- 実際の乗降動画から軌跡を抽出し、モデルの $T_\mathrm{dwell}$ 分布と比較するのは有力な卒研テーマである。
- 「どの行動を何割の人がとれば停車時間が最も縮むか」という最適混合の探索もできる。

## 演習問題

1. **（モデル化）** 一時降車型の移動コスト $C_i$ を大きくすると、効用 {eq}`eq-utility` 上でこの行動はどうなるか。協調が起きにくくなる条件を述べよ。
2. **（数値）** Notebook で固定型・横移動型・一時降車型の $T_\mathrm{dwell}$ 分布を箱ひげ図で比較し、中央値とばらつきの違いを述べよ。
3. **（数値）** ソフトマックスの $\lambda$ を小さくすると、$T_\mathrm{dwell}$ の分散はどう変わるか予想し、確かめよ。

## 発展課題

- 協調型の割合 $p$ を $0\%$ から $100\%$ まで変え、$T_\mathrm{dwell}$ の平均が $p$ にどう依存するか曲線を描け。閾値的な変化はあるか。
- 効用の重みを2人のタイプ（急ぐ人・気にしない人）で変え、混在させたときの流れを観察せよ。
