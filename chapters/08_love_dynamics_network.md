# 第8章　恋愛モデル II：複数人・三角関係・ネットワーク恋愛力学

:::{tip} 対応 Notebook
[08_love_dynamics_network.ipynb](../notebooks/08_love_dynamics_network.ipynb)

## この章の目的

第7章の2人モデルを、**複数人の有向重み付きネットワーク** に拡張する。三角関係や群像劇を感情行列で表し、嫉妬・応援・ライバル意識をモデル化する。物語の各話アノテーションとモデル予測を比較する枠組みを学ぶ。

:::{warning} 科学的な注意
本章も **仮想・作品分析用** の教材であり、実在人物の関係を評価するものではない。対象はドラマ・アニメ・仮想データとする。
:::

## 現象の説明

登場人物が3人以上になると、関係は「誰が誰をどう思うか」の網になる。Aが好きなBがCを好きだと、Aは嫉妬するかもしれない。第三者の存在が2者の関係を変える――これが2人モデルには無かった本質である。これを表すには、感情を **有向グラフの重み** として扱うのが自然である。

## 最小モデル

人物 $i$ が人物 $j$ に抱く感情を $x_{ij}(t)$ とする（有向：$x_{ij}\neq x_{ji}$ が普通）。これらをまとめた **感情行列**

```{math}
:label: eq-matrix
X(t) = \big(x_{ij}(t)\big)
```

を状態とする。$x_{ij}>0$ は好意、$x_{ij}<0$ は反感を表す。

## 数式による定式化

### 複数人モデル

各感情の変化率を、関係する感情の線形結合と外力で表す。

```{math}
:label: eq-network
\frac{dx_{ij}}{dt}
= a_{ij}\,x_{ij}
+ b_{ij}\,x_{ji}
+ \sum_{k\neq i,j} c_{ijk}\,x_{kj}
+ F_{ij}(t)
```

各項の意味：

- $a_{ij}x_{ij}$：自分の今の感情の持続・自己増幅（第7章の $a$）。
- $b_{ij}x_{ji}$：相手が自分をどう思うかへの反応（第7章の $b$）。両思いで増える、片思いで冷める等。
- $\sum_k c_{ijk}x_{kj}$：**第三者効果**。他者 $k$ が $j$ をどう思うかが、$i$ の $j$ への感情に影響する。$c_{ijk}<0$ なら「みんなが好きな人に嫉妬して引く」、$c_{ijk}>0$ なら「人気者をさらに好きになる」。
- $F_{ij}(t)$：物語イベント（告白、けんか、再会）による外力。

### 三角関係

3人 $\{A,B,C\}$ で、$c_{ijk}$ を嫉妬（負）に設定すると、$A\to B$、$B\to C$、$C\to A$ のように好意が回り続ける不安定な三角関係が表現できる。係数の符号パターンによって、関係が振動するか、特定のペアに収束するかが変わる。

### 物語との比較

各話 $t$ ごとに観測された感情変化 $\hat X_{t+1}$（アノテーション）と、モデル予測 $X_{t+1}$ を比べる。予測誤差は

```{math}
:label: eq-loss
L = \sum_t \big\| X_{t+1} - \hat X_{t+1} \big\|^2
```

で測る。$L$ を小さくする係数 $\{a_{ij}, b_{ij}, c_{ijk}\}$ を探すことが、物語の「感情の法則」を推定することに当たる。

## パラメータの意味

| 記号 | 意味 |
| --- | --- |
| $a_{ij}$ | 自己持続・自己増幅 |
| $b_{ij}$ | 相互性（両思いで強まるか） |
| $c_{ijk}$ | 第三者効果（嫉妬・応援・ライバル） |
| $F_{ij}(t)$ | 物語イベント |

人数 $n$ に対し感情は最大 $n(n-1)$ 個ある。係数は多いので、まず **三角関係（3人）** という最小ネットワークで挙動を理解する。

## 数値シミュレーション

Notebook では次を行う（seed 固定）。

1. 人物リスト（3〜4人）と感情行列 $X(0)$ を初期化する。
2. 更新規則 {eq}`eq-network` を数値積分（または離散更新）する。
3. 三角関係（嫉妬係数あり）のシナリオを実行する。
4. 外部イベント $F_{ij}(t)$ をある時刻に加える。
5. 各感情 $x_{ij}(t)$ の時系列をプロットする。
6. `networkx` で、ある時刻の感情を **有向グラフ**（辺の色＝符号、太さ＝強さ）として描く。
7. 仮想アノテーション $\hat X$ と予測 $X$ の誤差 {eq}`eq-loss` を計算する。

:::{note} 評価指標
評価指標は、時系列の **定性パターン**（収束／振動／発散）と、アノテーションとの **予測誤差 $L$**（式 {eq}`eq-loss`）である。ネットワーク図は補助で、必ず数値指標も出すこと。
:::

## 卒業研究への接続

- 実際のドラマ・アニメ・小説を各話アノテーションし、係数を推定する研究ができる。「この作品はどんな感情の法則で動くか」を定量化する。
- 第三者効果 $c_{ijk}$ の符号・大きさを変えると、群像劇の安定性がどう変わるかを調べられる。
- 人数を増やしたときの計算量・推定の難しさは、ネットワーク科学の一般的な課題につながる。

## 演習問題

1. **（モデル化）** 3人モデルで、すべての $c_{ijk}<0$（全員が嫉妬深い）とき、関係はどうなると予想するか。式 {eq}`eq-network` の符号から定性的に説明せよ。
2. **（数値）** Notebook で三角関係を実行し、感情の時系列が振動するパラメータと、特定ペアに収束するパラメータをそれぞれ見つけよ。
3. **（数値）** 仮想アノテーション $\hat X$ を1つ作り、係数を手で数通り変えて予測誤差 {eq}`eq-loss` を最小化せよ。最も $L$ が小さい係数の符号パターンを述べよ。

## 発展課題

- 4人に拡張し、2組のカップルが安定するパラメータと、全員がすれ違うパラメータを探せ。
- 係数推定を最小二乗（`numpy.linalg.lstsq`）で自動化し、与えたアノテーションから $a,b,c$ を復元できるか確かめよ。
